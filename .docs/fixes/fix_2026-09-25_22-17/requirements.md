## Исходный текст

СЦЕНА 1

1. После третьего фейкового клика Сцена 1 заканчивается и снова отображаются с фокусом все открытые окна.
2. После начала игры, то есть после начального клика, окна должны появляться в местах кликов не только по камню, но и по игровому полю.

## Функциональные требования

- **Завершение после третьего фейкового клика:** После начального клика система должна учитывать фейковые клики по камню. Третий фейковый клик должен завершать Сцену 1.
  - **Пояснение:** Постоянный режим фейковых кликов после второго клика больше не используется. Начальный клик запускает игру и не считается фейковым.
  - **Источник:** "После третьего фейкового клика сцена 1 заканчивается".
  - **Acceptance hint:** Начальный клик не меняет счётчик; первый и второй фейковые клики не завершают сцену; третий переводит сцену в завершённое состояние; дальнейшие игровые клики не создают новые окна.

- **Возврат всех окон на передний план:** При третьем фейковом клике система должна показать поверх основного окна все ранее открытые и ещё не закрытые popup-окна, включая окна от кликов по камню и игровому полю.
  - **Пояснение:** Третье окно, созданное самим завершающим кликом, также входит в отображаемый набор.
  - **Источник:** "отображаются снова (фокус) все открытые окна".
  - **Acceptance hint:** Если перед третьим фейковым кликом открыто несколько окон, после него каждое из них получает команду показа/фокуса и становится видимым.

- **Окна по кликам на игровом поле:** После начального клика каждый основной клик по свободной области игрового поля должен открывать одно окно в точке этого клика без необходимости отдельно включать настройку.
  - **Пояснение:** Клики по камню продолжают создавать окна по своей логике; элементы интерфейса, кнопки, ссылки, поля ввода и панель настроек не считаются игровым полем.
  - **Источник:** "После того как игра началась (после начального клика) начинай отрисовывать окна на местах клика не только по камню но и по полю".
  - **Acceptance hint:** До начального клика на поле окно не появляется; после него клик по свободному полю создаёт ровно одно окно; клик по UI окна не создаёт.

- **Независимость прогресса от кликов по полю:** Клики по свободному игровому полю должны создавать окна, но не засчитываться как один из трёх фейковых кликов и не завершать сцену.
  - **Пояснение:** Прогресс Сцены 1 изменяют только фейковые клики по камню.
  - **Источник:** "окна на местах клика не только по камню но и по полю".
  - **Acceptance hint:** Несколько кликов по полю не изменяют счётчик фейковых кликов и не завершают сцену.

## Нефункциональные требования

- **Привязка окна к координатам клика:** Центр нового окна должен располагаться максимально близко к экранным координатам клика с учётом ограничений рабочей области экрана.
  - **Пояснение:** У краёв экрана окно может быть сдвинуто внутрь доступной области операционной системой или расчётом геометрии.
  - **Источник:** "окна на местах клика по игровому полю".
  - **Acceptance hint:** Клики в разных частях поля создают окна в соответствующих частях экрана.

- **Отсутствие дублей:** Один пользовательский клик должен создавать не более одного окна, даже если событие обрабатывается и игровым полем, и камнем.
  - **Пояснение:** Делегированный обработчик игрового поля не должен дублировать popup, создаваемый обработчиком камня.
  - **Источник:** "не только по камню но и по полю".
  - **Acceptance hint:** Один клик по камню или полю увеличивает количество открытых окон не более чем на одно.

## Проблемы и замечания, превращённые в требования

- **Бесконечная третья стадия:** Сейчас третий и последующие фейковые клики продолжают отскоки без завершения. Требуемое поведение: третий фейковый клик завершает Сцену 1 и возвращает открытые окна на передний план.
  - **Источник:** "После третьего фейкового клика сцена 1 заканчивается".
  - **Acceptance hint:** После третьего фейкового клика `sceneFlow.completed` принимает значение `true`, а новые игровые окна больше не создаются.

- **Окна по полю выключены настройкой:** Сейчас после запуска игры клик по полю может не открыть окно из-за выключенной опции. Требуемое поведение: открытие окна по клику на игровое поле является штатным поведением Сцены 1 после старта.
  - **Источник:** "начинай отрисовывать окна на местах клика не только по камню но и по полю".
  - **Acceptance hint:** Поведение работает с настройками Сцены 1 по умолчанию.

## Открытые вопросы

- Блокирующих вопросов нет.
- «Фокус всех окон» трактуется как последовательный вызов показа/фокуса для каждого открытого окна. Операционная система сохраняет активный клавиатурный фокус только у одного окна одновременно.
