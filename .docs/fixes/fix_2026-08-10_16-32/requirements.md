## Функциональные требования

- **Частичное вхождение в стены:** система должна позволять камню пересекать нижнюю, левую и правую границы на заданный процент своего размера и ограничивать дальнейшее проникновение.
  - **Пояснение:** для нижней стены процент рассчитывается от высоты камня, для боковых стен — от его ширины.
  - **Источник:** «Позволяй камню зайти вниз и в боковые стены на 20%».
  - **Acceptance hint:** при значении `20%` камень входит в нижнюю стену максимум на 20% своей высоты, а в боковую — максимум на 20% своей ширины.

- **Настройка глубины вхождения:** система должна предоставлять на UI единый параметр допустимого вхождения камня в нижнюю и боковые стены.
  - **Пояснение:** значение по умолчанию при отсутствии сохранённых настроек — `20%`; изменение параметра влияет на ограничение движения камня.
  - **Источник:** «добавь это параметр на UI».
  - **Acceptance hint:** UI показывает параметр в процентах, а изменение значения меняет допустимую глубину пересечения границ.

- **Сохранение всех UI-параметров:** система должна сохранять значения всех настраиваемых параметров UI и восстанавливать их при следующем запуске.
  - **Пояснение:** восстановленные значения должны использоваться не только элементами UI, но и логикой приложения.
  - **Источник:** «все параметры на UI должны сохраняться между запусками».
  - **Acceptance hint:** изменить несколько параметров, штатно закрыть приложение и запустить снова — UI и поведение приложения используют сохранённые значения.

## Нефункциональные требования

- **Понятность настройки:** UI должен явно показывать, что глубина вхождения измеряется в процентах и применяется к нижней и боковым стенам.
  - **Пояснение:** назначение и единица измерения параметра должны быть понятны без обращения к документации.
  - **Источник:** «добавь это параметр на UI».
  - **Acceptance hint:** рядом с контролом присутствуют понятное название и обозначение процентов.

- **Стабильное ограничение:** система должна ограничивать проникновение камня без дрожания, проваливания глубже заданного значения или полного прохождения через границу.
  - **Пояснение:** изменение допустимого пересечения не должно ухудшать стабильность движения камня у стен.
  - **Источник:** «Позволяй камню зайти вниз и в боковые стены на 20%».
  - **Acceptance hint:** при движении и удержании направления в сторону стены камень остаётся в пределах разрешённой глубины.

- **Надёжность сохранения:** сохранённые UI-параметры должны переживать штатное завершение и повторный запуск приложения.
  - **Пояснение:** пользовательские настройки не должны самопроизвольно сбрасываться.
  - **Источник:** «все параметры на UI должны сохраняться между запусками».
  - **Acceptance hint:** повторный запуск восстанавливает последние сохранённые значения.

- **Согласованность состояния:** восстановленные значения должны совпадать в элементах UI и в фактическом поведении приложения.
  - **Пояснение:** визуальное состояние контролов не должно расходиться с активными настройками логики.
  - **Источник:** «все параметры на UI должны сохраняться между запусками».
  - **Acceptance hint:** после запуска каждый контрол показывает то же значение, которое применено соответствующей подсистемой.

## Проблемы и замечания, превращённые в требования

- **Недостаточная глубина контакта со стенами:** сейчас камень не может контролируемо заходить в нижнюю и боковые стены на требуемую глубину. Требуемое поведение: разрешать пересечение в пределах установленного процента.
  - **Источник:** «Позволяй камню зайти вниз и в боковые стены на 20%».
  - **Acceptance hint:** визуальная и физическая граница движения соответствует выбранному значению.

- **Сброс UI-параметров:** UI-параметры не должны сбрасываться после перезапуска. Требуемое поведение: все пользовательские значения автоматически восстанавливаются.
  - **Источник:** «все параметры на UI должны сохраняться между запусками».
  - **Acceptance hint:** несколько изменённых параметров сохраняются и восстанавливаются совместно.

## Не включено / требует уточнения

- Верхняя граница не изменяется, поскольку пользователь указал только нижнюю и боковые стены.
- Для нижней и боковых стен используется один общий параметр; отдельные значения не запрошены.
- Синхронизация настроек между устройствами не включена; требуется локальное сохранение между запусками.
