## Исходный текст

Пользователь потребовал не останавливать уже запущенные звуки при старте новых, а накладывать независимые воспроизведения. Для Сцены 2 необходимо добавить UI-параметр показа или скрытия `overflow-y`; значение по умолчанию и значение миграции — «Скрыть».

---

## Функциональные требования

- **Наложение звуков:** При повторном запуске one-shot звукового эффекта система должна создавать независимое воспроизведение, не останавливая ранее запущенные экземпляры.
  - **Пояснение:** Быстрые повторные клики по камню в Сцене 2 должны накладывать выбранные gachi-звуки друг на друга. Такое же поведение применяется к остальным повторно запускаемым one-shot эффектам; фоновые и зацикленные аудиопотоки не затрагиваются.
  - **Источник:** "Не перекрывай звуки (проблема: сейчас запущенный звук останавливается и перекрывается новым). Не перекрывай а накладывай их"
  - **Acceptance hint:** Несколько быстрых кликов запускают несколько одновременно звучащих экземпляров, каждый из которых доигрывает самостоятельно.

- **Управление `overflow-y` Сцены 2:** В параметрах Сцены 2 должен появиться переключатель «Вертикальная прокрутка» со значениями «Показать» и «Скрыть».
  - **Пояснение:** «Показать» устанавливает `overflow-y: auto`, «Скрыть» — `overflow-y: hidden`. Настройка применяется сразу, сохраняется с остальными параметрами и отображается только для Сцены 2. Значение по умолчанию и значение при миграции существующих настроек — «Скрыть».
  - **Источник:** "Сцена 2: Добавь на UI параметр скрыть / показать overflow-y"; уточнение: "overflow-y по умолчанию скрыть"
  - **Acceptance hint:** При первом запуске вертикальный overflow скрыт; после выбора «Показать» вертикальная прокрутка становится доступна без перезапуска сцены.

## Нефункциональные требования

- **Независимость аудиоэкземпляров:** Запуск или завершение одного one-shot звука не должно прерывать другие активные звуки.
  - **Пояснение:** Каждый запуск имеет собственный жизненный цикл воспроизведения.
  - **Источник:** "Не перекрывай а накладывай их"
  - **Acceptance hint:** Завершение одного из наложенных экземпляров не влияет на остальные.

- **Освобождение ресурсов:** Завершившиеся аудиоэкземпляры должны освобождаться и не оставаться в коллекции активных воспроизведений.
  - **Пояснение:** Наложение не должно приводить к накоплению завершившихся экземпляров.
  - **Источник:** Требование независимого наложения звуков.
  - **Acceptance hint:** После естественного завершения всех звуков активные экземпляры отсутствуют.

- **Совместимость камеры:** Скрытый `overflow-y` не должен мешать программному lerp-следованию камеры за камнем.
  - **Пояснение:** UI-настройка визуального overflow не должна ломать действующую механику камеры Сцены 2.
  - **Источник:** Требование управления `overflow-y` в Сцене 2.
  - **Acceptance hint:** При `overflow-y: hidden` камера продолжает программно следовать за камнем вверх и вниз согласно настройкам.

## Проблемы и замечания, превращённые в требования

- **Прерывание активного звука:** Сейчас новый звук принудительно останавливает предыдущий. Требуемое поведение: одновременно могут воспроизводиться несколько экземпляров, включая копии одного файла.
  - **Источник:** "сейчас запущенный звук останавливается и перекрывается новым"
  - **Acceptance hint:** Серия быстрых кликов не вызывает преждевременного завершения ранее запущенных звуков.

- **Отсутствие управления вертикальным overflow:** Сейчас пользователь не может управлять `overflow-y` Сцены 2. Требуемое поведение: состояние выбирается через UI, сохраняется и по умолчанию установлено в «Скрыть».
  - **Источник:** "Добавь на UI параметр скрыть / показать overflow-y"
  - **Acceptance hint:** Контрол доступен только в Сцене 2 и корректно восстанавливает сохранённое значение.
