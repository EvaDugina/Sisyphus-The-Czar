## Исходный текст

Пользователь запросил:

- убрать отдельный плавный скролл после достижения камнем вершины и включения светлой темы;
- добавить включаемое на UI автоматическое выскальзывание неподвижного камня;
- добавить позиционный скролл при входе центра камня в настраиваемую верхнюю зону viewport, с настраиваемыми начальной и конечной скоростями и кривой `cubic-bezier`;
- добавить наглядный редактор и preview для каждого UI-параметра типа `cubic-bezier` по образцу `cubic-bezier.com`;
- добавить управление ручным вертикальным скроллом без блокировки программного скролла;
- перенести точку привязки линии в центр нижней границы камня и сделать её высоту настраиваемой;
- изменить шаг параметра «Пружинистость» на `0.01`;
- заменить «Минимальный размер» и «Максимальный размер» на «Начальный размер» и «Конечный размер» и снять взаимное ограничение значений;
- сохранять новые параметры тем же способом, что и текущие настройки.

## Функциональные требования

- **Удаление завершающего скролла:** после достижения камнем верхней точки и включения светлой темы система не должна запускать отдельный плавный скролл страницы к верхушке.
  - **Пояснение:** Переход на светлую тему сохраняется, но не сопровождается отдельным программным перемещением страницы.
  - **Источник:** "Убери плавный scroll к верхушке после касания камнем своей верхней точки после которой наступает светлая тема."
  - **Acceptance hint:** Достижение вершины включает светлую тему без дополнительного завершающего скролла.

- **Переключатель автоматического выскальзывания:** на UI должен находиться переключатель автоматического выскальзывания неподвижного камня до достижения вершины.
  - **Пояснение:** Значение по умолчанию — `true`. При `true` существующий механизм работает без изменения; при `false` неподвижность не вызывает принудительное выскальзывание. Текущие критерий неподвижности, задержка и физика сохраняются.
  - **Источник:** "Добавь возможность на UI включить/выключить автоматическое выскальзывание камня, если камень не движется (до достижения верхушки)."
  - **Acceptance hint:** В одинаковой ситуации автоматическое выскальзывание происходит только при включённом параметре.

- **Позиционный автоматический скролл:** до достижения вершины система должна автоматически прокручивать страницу вверх, когда центр камня входит в заданную верхнюю зону viewport.
  - **Пояснение:** Положение рассчитывается относительно видимой области браузера, а не полной высоты документа. При достижении вершины позиционный скролл прекращается и не переходит в отдельный завершающий скролл.
  - **Источник:** "Добавь медленный scroll к верхушке если центр камня в верхних 20% от размера экрана (не высоты страницы)."
  - **Acceptance hint:** При зоне `20%` скролл начинается после входа центра камня в верхние `20%` viewport.

- **Переключатель позиционного скролла:** на UI должен находиться переключатель скролла, зависящего от положения камня.
  - **Пояснение:** Значение по умолчанию — `true`. При `false` положение камня не вызывает автоматическую прокрутку; ручной и иной программный скролл не затрагиваются.
  - **Источник:** "Добавь на UI возможность включить / отключить."
  - **Acceptance hint:** Камень в зоне запускает позиционный скролл только при включённом параметре.

- **Размер верхней зоны:** на UI должен находиться числовой параметр доли высоты viewport от верхней границы, внутри которой работает позиционный скролл.
  - **Пояснение:** Диапазон `0–20%`, значение по умолчанию `20%`, шаг `0.1` процентного пункта. Положение проверяется по центру камня. При `0%` зона отсутствует.
  - **Источник:** "Отрегулировать % от верха экрана с которого должен начинаться плавный scroll."
  - **Acceptance hint:** UI не принимает значения вне `0–20`, а изменение порога меняет границу запуска.

- **Начальная скорость скролла:** параметр должен определять скорость в момент входа центра камня в верхнюю зону.
  - **Пояснение:** Диапазон `0–2`, значение по умолчанию `0.2`, шаг `0.01`.
  - **Источник:** "Начальная скорость scroll (когда камень в самом начале зоны)."
  - **Acceptance hint:** На границе зоны используется настроенное начальное значение.

- **Конечная скорость скролла:** параметр должен определять скорость при достижении центром камня верхней границы viewport.
  - **Пояснение:** Диапазон `0–2`, значение по умолчанию `1`, шаг `0.01`.
  - **Источник:** "Конечная скорость scroll (когда камень в 0% от верха экрана)."
  - **Acceptance hint:** На отметке `0%` используется настроенное конечное значение.

- **Интерпретация скорости:** значение скорости должно отображаться как безразмерный коэффициент, а фактическое перемещение — нормализоваться относительно высоты viewport.
  - **Пояснение:** Коэффициент `1` соответствует `1vh`, коэффициент `0.2` — `0.2vh` за один шаг алгоритма скролла.
  - **Источник:** "Безразмерный в vh."
  - **Acceptance hint:** При разных высотах viewport одинаковый коэффициент даёт одинаковую относительную скорость.

- **Кривая изменения скорости:** интерполяция скорости между границей зоны и верхней границей viewport должна вычисляться с помощью `cubic-bezier`.
  - **Пояснение:** Начало кривой соответствует начальной скорости, конец — конечной. Значение по умолчанию: `cubic-bezier(.17,.67,.83,.67)`.
  - **Источник:** "Добавь на UI кривую по которой она должна изменяться." / "cubic-bezier(.17,.67,.83,.67)"
  - **Acceptance hint:** Изменение кривой меняет промежуточную скорость, сохраняя заданные скорости на концах.

- **Наглядный редактор `cubic-bezier`:** каждый UI-параметр приложения, принимающий `cubic-bezier`, включая кривую скорости скролла, должен управляться через визуальный редактор по образцу `curve-display` на `https://cubic-bezier.com/`.
  - **Пояснение:** Редактор содержит график «время/прогресс», результирующую кривую, две перетаскиваемые управляющие точки, поля `x1`, `y1`, `x2`, `y2` с шагом `0.01`, итоговую строку и двустороннюю синхронизацию графика и чисел.
  - **Источник:** "Каждый параметр который принимает cubic-bezier должен управляться наглядно, как секции curve-display и preview вот здесь https://cubic-bezier.com/."
  - **Acceptance hint:** Перетаскивание точки обновляет числа и строку, а изменение числа обновляет график.

- **Предварительный просмотр кривой:** рядом с редактором должен находиться самостоятельный блок визуального воспроизведения кривой по образцу `Preview & compare`.
  - **Пояснение:** Пользователь может повторно запустить preview; он демонстрирует текущую кривую, обновляется после редактирования и не меняет состояние камня или страницы.
  - **Источник:** "как секции curve-display и preview вот здесь https://cubic-bezier.com/."
  - **Acceptance hint:** Preview воспроизводится повторно и визуально меняется после изменения кривой.

- **Управление `overflow-y`:** на UI должен находиться переключатель ручной вертикальной прокрутки.
  - **Пояснение:** Значение по умолчанию — `true`. При `false` блокируется только ручной вертикальный скролл; программный позиционный скролл продолжает работать. Возврат `true` восстанавливает ручную прокрутку.
  - **Источник:** "Добавь на UI возможность отключить overflow-y." / "Только ручной."
  - **Acceptance hint:** При выключенном параметре колесо/жест не прокручивает страницу, но позиционный скролл работает.

- **Вертикальное положение точки линии:** линия или траектория камня должна строиться относительно настраиваемой точки на вертикальной центральной оси изображения камня.
  - **Пояснение:** Горизонтально точка всегда находится по центру. Вертикальное положение задаётся в диапазоне `0–100%` с шагом `1`: `0%` — верхняя граница, `100%` — нижняя. Значение по умолчанию — `100%`.
  - **Источник:** "В центр нижней границы. Добавь на UI возможность изменять по высоте точку относительно которой чертится траектория камня в процентах относительно высоты изображения камня."
  - **Acceptance hint:** При `100%` линия привязана снизу по центру; изменение процента смещает только точку линии.

- **Точность настройки пружинистости:** цена деления UI-параметра «Пружинистость» должна составлять `0.01`.
  - **Пояснение:** Существующие индивидуальные границы и значение по умолчанию сохраняются.
  - **Источник:** "Уменьши на UI цену деления параметра пружинистость до 0.01."
  - **Acceptance hint:** Соседние доступные значения отличаются на `0.01`.

- **Переименование размеров:** параметры «Минимальный размер» и «Максимальный размер» должны называться «Начальный размер» и «Конечный размер».
  - **Пояснение:** Названия отражают размер камня в начале и конце пути.
  - **Источник:** "Измени названия параметров камня «Минимальный размер» и «Максимальный размер» в Начальный и конечный размер."
  - **Acceptance hint:** Старые подписи отсутствуют, новые отображаются на UI.

- **Независимые размеры камня:** начальный размер должен определять размер камня в начале пути, а конечный — в конце.
  - **Пояснение:** Допустимы все взаимные отношения значений. Система не переставляет их местами, не ограничивает одно другим и позволяет камню увеличиваться, уменьшаться или сохранять размер. Существующий способ вычисления прогресса пути сохраняется.
  - **Источник:** "Исправь их логику (теперь один не обязан быть больше другого)."
  - **Acceptance hint:** Работают случаи `начальный < конечного`, `начальный > конечного` и равенство.

- **Сохранение настроек:** новые настройки должны сохраняться и восстанавливаться после перезагрузки тем же механизмом, который используется текущими UI-параметрами.
  - **Пояснение:** Сохраняются автоматическое выскальзывание, позиционный скролл, размер зоны, обе скорости, четыре координаты `cubic-bezier`, `overflow-y` и высота точки линии.
  - **Источник:** "Как и текущие."
  - **Acceptance hint:** После изменения и перезагрузки все перечисленные значения восстанавливаются.

## Нефункциональные требования

- **Плавность:** вычисление скорости по кривой не должно создавать непредусмотренных скачков страницы.
  - **Пояснение:** Динамика следует непрерывной пользовательской кривой.
  - **Источник:** "плавный scroll"
  - **Acceptance hint:** При непрерывной кривой скорость визуально меняется без скачков.

- **Независимость от разрешения:** зона и скорость должны масштабироваться относительно viewport.
  - **Пояснение:** Настройки одинаково интерпретируются при разных разрешениях экрана.
  - **Источник:** "не высоты страницы" / "в vh"
  - **Acceptance hint:** Изменение высоты viewport сохраняет относительные порог и скорость.

- **Корректность при изменении viewport:** координаты зоны и величина `vh` должны пересчитываться после изменения размера окна.
  - **Пояснение:** Расчёты не должны использовать устаревшую высоту.
  - **Источник:** "от размера экрана"
  - **Acceptance hint:** После resize зона запуска и величина шага соответствуют новому viewport.

- **Разделение механизмов:** запрет ручного скролла не должен блокировать программный скролл.
  - **Пояснение:** Настройки ручного и позиционного скролла независимы.
  - **Источник:** "Только ручной."
  - **Acceptance hint:** При заблокированном ручном скролле программный скролл остаётся работоспособным.

- **Синхронность редактора:** график, управляющие точки, числовые поля, строка `cubic-bezier` и preview должны представлять одно актуальное значение.
  - **Пояснение:** Любой способ редактирования приводит UI к согласованному состоянию.
  - **Источник:** "должен управляться наглядно"
  - **Acceptance hint:** После любого редактирования все представления содержат одни координаты.

- **Обратная совместимость:** значения по умолчанию должны сохранять включёнными автоматическое выскальзывание, позиционный скролл и ручную вертикальную прокрутку.
  - **Пояснение:** Все три новых переключателя по умолчанию равны `true`.
  - **Источник:** "True."
  - **Acceptance hint:** На чистых настройках все три переключателя включены.

- **Совместимость сохранения:** новые параметры должны использовать действующий механизм хранения и восстановления настроек.
  - **Пояснение:** Не создаётся параллельный несовместимый механизм хранения.
  - **Источник:** "Как и текущие."
  - **Acceptance hint:** Новые поля проходят тот же lifecycle, что текущие настройки.

## Проблемы и замечания, превращённые в требования

- **Нежелательный скролл после вершины:** сейчас достижение вершины запускает отдельное движение страницы. Требуемое поведение: светлая тема включается без завершающего скролла.
  - **Источник:** "Убери плавный scroll к верхушке после касания камнем своей верхней точки."
  - **Acceptance hint:** После вершины отсутствует новый scroll animation.

- **Жёсткая зависимость размеров:** сейчас значения трактуются как взаимозависимые минимум и максимум. Требуемое поведение: независимые начальный и конечный размеры.
  - **Источник:** "Один не обязан быть больше другого."
  - **Acceptance hint:** Оба направления изменения размера допустимы.

- **Неверная точка линии:** сейчас линия строится относительно центра камня. Требуемое поведение: точка по умолчанию находится снизу по центру и регулируется по высоте.
  - **Источник:** "Смести точку ... с середины вниз камня."
  - **Acceptance hint:** При значении `100%` точка совпадает с центром нижней границы изображения.

- **Недостаточная точность пружинистости:** сейчас UI не предоставляет требуемую точность. Требуемое поведение: шаг равен `0.01`.
  - **Источник:** "Уменьши ... цену деления ... до 0.01."
  - **Acceptance hint:** UI позволяет выбрать значение с точностью до сотых.

- **Отсутствие контроля автоматического поведения:** сейчас пользователь не может независимо управлять выскальзыванием и позиционным скроллом. Требуемое поведение: отдельный переключатель для каждого механизма.
  - **Источник:** "Добавь возможность на UI включить/выключить."
  - **Acceptance hint:** Оба механизма независимо включаются и отключаются.

- **Отсутствие контроля ручного скролла:** сейчас пользователь не может заблокировать только ручную вертикальную прокрутку. Требуемое поведение: отдельный переключатель не влияет на программный скролл.
  - **Источник:** "Добавь на UI возможность отключить overflow-y." / "Только ручной."
  - **Acceptance hint:** Ручное и программное перемещения управляются независимо.

## Не включено / требует уточнения

- Библиотека кривых, импорт, экспорт и копирование ссылки с референсного сайта не требуются.
- Точное визуальное копирование оформления `cubic-bezier.com` не требуется: референс задаёт состав и интерактивность редактора.
- Текущие критерий неподвижности, задержка и физика автоматического выскальзывания не меняются.
- Формула прогресса изменения размера камня не меняется.
