## Исходный текст

Пользователь выключил звук руки и сохранил настройки, однако после перезагрузки снова воспроизводится звук «Кандалы». В окне настроек невозможно установить флаг на конфигурацию. Требуется, чтобы после перезагрузки использовалась только конфигурация, помеченная флагом.

---

## Функциональные требования

- **Рабочий флаг в окне настроек:** Окно настроек должно обрабатывать текущее и обновлённое состояние production preset, полученное от сервера, и разрешать установку флага при `DEBUG=true`.
  - **Пояснение:** Пользователь должен иметь возможность назначить сохранённую конфигурацию стартовой из отдельного окна настроек.
  - **Источник:** «Почему я не могу поставить флаг на конфигурацию?»
  - **Acceptance hint:** После подключения кнопка флага активна; нажатие сохраняет выбор и сразу обновляет отметку в интерфейсе.

- **Единственная помеченная конфигурация:** В каждый момент времени должна существовать не более чем одна активная конфигурация. Установка нового флага должна атомарно снимать предыдущий.
  - **Пояснение:** Стартовая конфигурация должна определяться однозначно.
  - **Источник:** «Пусть при перезагрузке используется только конфигурация помеченная флагом!»
  - **Acceptance hint:** После выбора новой версии флаг отображается только у неё, а сервер возвращает только один активный production preset.

- **Приоритет помеченной конфигурации:** При полной перезагрузке приложения и создании новой сессии система должна загружать настройки только из конфигурации, помеченной флагом.
  - **Пояснение:** Порядок сохранения версий не должен менять стартовое поведение приложения.
  - **Источник:** «Пусть при перезагрузке используется только конфигурация помеченная флагом!»
  - **Acceptance hint:** Более новая непомеченная версия не применяется после reload и при создании новой сессии.

- **Игнорирование непомеченных версий:** Последняя по времени, локально выбранная или недавно сохранённая конфигурация не должна автоматически становиться стартовой, если она не помечена флагом.
  - **Пояснение:** Флаг является единственным пользовательским механизмом выбора стартовой конфигурации.
  - **Источник:** «используется только конфигурация помеченная флагом»
  - **Acceptance hint:** Изменение `updatedAt` непомеченной версии не меняет настройки следующего запуска.

- **Восстановление настройки звука:** Поле `handAudioEnabled` должно загружаться из помеченной конфигурации. Если оно равно `false`, звуки руки и «Кандалы» не должны воспроизводиться после reload.
  - **Пояснение:** Сохранённое отключение звука должно влиять на фактическое поведение сцены.
  - **Источник:** «я выключил звук руки и сохранил, но при перезагрузке звук Кандалы все равно воспроизводится»
  - **Acceptance hint:** В помеченной версии с `handAudioEnabled: false` ни наведение, ни взаимодействие с рукой не запускает аудио после reload.

- **Подтверждение выбора:** После установки флага интерфейс должен показывать имя активной конфигурации. Ошибка сохранения должна отображаться явно и не создавать ложную отметку.
  - **Пояснение:** Пользователь должен понимать, применилось ли действие.
  - **Источник:** «Почему я не могу поставить флаг на конфигурацию?»
  - **Acceptance hint:** Успешный ответ обновляет флаг и статус; ошибка оставляет прежний флаг и показывает сообщение.

## Нефункциональные требования

- **Предсказуемость:** Одинаковая помеченная конфигурация должна давать одинаковые стартовые настройки в dev, debug-production и slim production.
  - **Пояснение:** Режим сборки не должен менять семантику флага.
  - **Источник:** «при перезагрузке используется только конфигурация помеченная флагом»
  - **Acceptance hint:** Релевантные unit/integration проверки подтверждают единый источник стартовых настроек.

- **Надёжность:** При отсутствии или повреждении помеченной конфигурации система не должна молча выбирать последнюю непомеченную версию; должен применяться безопасный встроенный fallback с диагностикой.
  - **Пояснение:** Ошибка файла конфигурации не должна давать непредсказуемый выбор версии.
  - **Источник:** Требование использовать только помеченную конфигурацию.
  - **Acceptance hint:** При недоступном production preset применяется встроенный preset, а непомеченный шаблон не используется.

- **Совместимость:** Формат существующих `settings-templates.json` и `production-preset.json` должен остаться поддерживаемым.
  - **Пояснение:** Исправление не должно требовать ручной миграции отслеживаемых конфигураций.
  - **Источник:** Существующий механизм сохранённых конфигураций и флага.
  - **Acceptance hint:** Текущие fixture-файлы успешно загружаются существующими хранилищами.

## Проблемы и замечания, превращённые в требования

- **Окно настроек игнорирует состояние флага:** Сейчас отдельное окно настроек не обрабатывает сообщения `productionPreset.current` и `productionPreset.selected`, поэтому кнопка остаётся заблокированной. Требуемое поведение: окно получает состояние, активирует кнопку и отображает установленный флаг.
  - **Источник:** «Почему я не могу поставить флаг на конфигурацию?»
  - **Acceptance hint:** Обработчик обоих сообщений вызывает обновление production preset state контроллера.

- **Debug выбирает последнюю версию:** Сейчас стартовая логика при `DEBUG=true` использует `settingsTemplateStore.latest()`. Требуемое поведение: источником стартовых настроек является помеченный production preset.
  - **Источник:** «используется только конфигурация помеченная флагом»
  - **Acceptance hint:** Более новый непомеченный шаблон не попадает в новую сессию.

- **Активный preset возвращает звук по умолчанию:** Сейчас помеченный `builtin-prod-v32` не содержит `handAudioEnabled`, поэтому нормализация подставляет `true`. Требуемое поведение: после выбора сохранённой версии со значением `false` это значение используется при reload.
  - **Источник:** «при перезагрузке звук Кандалы все равно воспроизводится»
  - **Acceptance hint:** Помеченная версия с выключенным звуком создаёт сессию с `roomSettings.handAudioEnabled === false`.

## Не включено / требует уточнения

- Возможность менять флаг при `DEBUG=false` не включена: в настоящем production окно настроек отсутствует. Флаг должен работать во всех режимах, где окно настроек доступно.
