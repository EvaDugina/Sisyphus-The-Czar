1. Разделить каждую берёзу из `background_01` в отдельный PNG по прозрачным промежуткам, разместить берёзы в сцене 1 на нижнем участке высотой `100vh` и чередовать их глубину относительно камня. Две центральные берёзы должны находиться выше камня.

## Функциональные требования

- **Разделение берёз:** Система должна использовать 9 отдельных PNG-ассетов, полученных из `assets/background/background_01.png` по прозрачным промежуткам без перерисовки исходных пикселей.
  - **Пояснение:** Каждая визуально отделённая берёза становится самостоятельным слоем сцены.
  - **Источник:** "Вырежи каждую березу из фотографии background_01 в отдельный png-файл раздели их по alpha 0".
  - **Acceptance hint:** Создано 9 PNG-файлов; каждый содержит одну берёзу и корректный alpha-канал.

- **Размещение берёз в сцене 1:** Система должна распределить отдельные берёзы по ширине нижнего участка сцены высотой `100vh`, не распространяя композицию на остальные участки длинной страницы.
  - **Пояснение:** Берёзы образуют композицию первой сцены в пределах нижнего viewport-экрана.
  - **Источник:** "Помести их на сцене 1 на разных уровнях z-index по всей высоте нижней страницы (100 vh)".
  - **Acceptance hint:** Берёзовый слой занимает нижние `100vh` сцены и адаптируется к ширине viewport.

- **Чередование глубины:** Система должна поочерёдно располагать берёзы ниже и выше камня по `z-index`, чтобы камень проходил за одними стволами и отображался поверх других; две центральные берёзы должны обе находиться выше камня.
  - **Пояснение:** Явное правило центральной пары имеет приоритет над общим чередованием.
  - **Источник:** "через одну дай камню заходить по z-index за одни и быть над других. По середине две стоящие березы должны быть выше камня".
  - **Acceptance hint:** При движении камня видимо чередование перекрытий, а обе центральные берёзы всегда перекрывают камень.

- **Картины во всплывающем окне:** Система должна при каждом фейковом клике показывать в popup-окне одну из картин `assets/gogh/01.png`, `02.png`, `03.png` вместо изображения камня, последовательно меняя картины по циклу `01 → 02 → 03 → 01`.
  - **Пояснение:** Принята утверждённая последовательная циклическая смена; файл с UUID из папки `gogh` не используется.
  - **Источник:** "При всплывании окна отрисовывай в нем картины 01-03 из папки gogh".
  - **Acceptance hint:** Первые три popup-окна показывают `01`, `02`, `03`, четвёртое снова показывает `01`; изображение камня не появляется.

- **Звук фейкового клика:** Система не должна воспроизводить `Camen.mp3` при фейковом клике и должна использовать существующий `Смех.mp3` как единственный звуковой отклик, воспроизводимый один раз.
  - **Пояснение:** Уже существующий звук отскока остаётся единственным звуком события; отдельный вызов `Camen` удаляется, чтобы не дублировать смех.
  - **Источник:** "Убери звук Camen после фейкового клика и замени его на Смех".
  - **Acceptance hint:** Один фейковый клик создаёт одно воспроизведение `Смех.mp3` и ни одного воспроизведения `Camen.mp3`.

## Нефункциональные требования

- **Точное сохранение растров:** Система должна сохранять исходные пиксели, прозрачность и границы берёз без генеративных изменений.
  - **Пояснение:** Разделение является детерминированной операцией над alpha-каналом исходника.
  - **Источник:** "раздели их по alpha 0".
  - **Acceptance hint:** Совмещение отдельных PNG в исходных координатах воспроизводит исходное изображение.

- **Неперехватывающие декоративные слои:** Берёзовые изображения не должны перехватывать ввод или мешать перетаскиванию камня.
  - **Пояснение:** Декоративная композиция не изменяет управление сценой.
  - **Источник:** Требование размещения берёз относительно интерактивного камня.
  - **Acceptance hint:** Камень можно захватывать и перетаскивать сквозь прозрачные и непрозрачные участки берёз.

- **Адаптивность композиции:** Система должна сохранять размещение и заданные перекрытия берёз на поддерживаемых размерах viewport.
  - **Пояснение:** Нижний участок сцены остаётся цельной композицией на desktop и mobile.
  - **Источник:** "по всей высоте нижней страницы (100 vh)".
  - **Acceptance hint:** На desktop и mobile берёзы остаются в нижних `100vh`, а центральная пара перекрывает камень.

- **Сохранение пропорций картин:** Popup должен помещать выбранную картину без искажения её пропорций.
  - **Пояснение:** Размер окна и режим отображения учитывают фактическое соотношение сторон выбранного изображения.
  - **Источник:** "отрисовывай в нем картины 01-03".
  - **Acceptance hint:** Картины целиком помещаются в popup и не растягиваются по одной оси.
