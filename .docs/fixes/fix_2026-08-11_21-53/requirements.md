## Функциональные требования

- **Следование камеры за падающим камнем:** система должна предоставить в параметрах сцены 2 переключатель «Следовать камерой при падении».
  - **Пояснение:** при включённом параметре камера плавно прокручивается вниз вслед за падающим камнем с использованием lerp; при выключенном падение камня не вызывает прокрутку вниз. Значение по умолчанию — включено.
  - **Источник:** «Когда камень падает вниз продолжай следовать камерой за ним с lerp (добавь параметр следовать или нет на UI)».
  - **Acceptance hint:** при включённом параметре камера без скачков следует вниз за падающим камнем; после отключения положение камеры не меняется из-за падения камня.

- **Управление автоскроллом верхней области:** система должна предоставить в параметрах сцены 2 переключатель «Автоскролл в верхней области».
  - **Пояснение:** значение по умолчанию — выключено. В выключенном состоянии помещение или удержание камня в верхней области не запускает и не продолжает автоскролл. Отключение параметра во время активного автоскролла останавливает его немедленно. При включении работает существующее автоматическое движение вверх.
  - **Источник:** «Добавь на UI параметр Выключить / Включить автоскролл при помещении камня в верхнюю часть (сейчас когда камень вверху почему-то остается автоскролл)».
  - **Acceptance hint:** при выключенном параметре автоскролл не возобновляется самопроизвольно и прекращается после выхода камня из верхней области.

- **Выбор звука клика по камню:** система должна предоставить в параметрах сцены 2 выпадающий список со звуками из `assets/audio/gachi`.
  - **Пояснение:** по умолчанию выбран `Camen.mp3`. Обычный завершённый клик или тап по камню воспроизводит выбранный звук один раз. Перетаскивание не создаёт повторные срабатывания одного жеста.
  - **Источник:** «По клику на камень дай на UI выбрать один звук из папки gachi (по-умолчанию это звук Сamen)».
  - **Acceptance hint:** список содержит поддерживаемые звуки папки `gachi`, `Camen.mp3` выбран изначально, а смена значения изменяет следующий воспроизводимый звук.

- **Смех только при фейковых кликах:** система должна воспроизводить `Смех.mp3` в сцене 1 ровно один раз для каждого фейкового клика.
  - **Пояснение:** смех не воспроизводится при отскоке от приближения руки, обычном захвате, активационном клике, клике в сцене 2 или других событиях.
  - **Источник:** «Сцена 1: включай звук \"смех\" тольк при фейковых кликах».
  - **Acceptance hint:** серия фейковых кликов сопровождается смехом, а остальные взаимодействия — нет.

## Нефункциональные требования

- **Плавность камеры:** камерная анимация должна работать без скачков, дрожания и конфликта между lerp-слежением и автоскроллом верхней области.
  - **Пояснение:** два механизма прокрутки должны иметь однозначные условия активации и остановки.
  - **Источник:** «продолжай следовать камерой за ним с lerp» и замечание об остающемся автоскролле.
  - **Acceptance hint:** при смене направления движения камня и переключении параметров камера остаётся стабильной.

- **Совместимость настроек:** новые параметры должны размещаться в UI сцены 2 и сохраняться через существующий механизм настроек, шаблонов и production preset.
  - **Пояснение:** новые элементы должны вести себя так же, как соседние параметры сцены 2.
  - **Источник:** требования добавить параметры «на UI».
  - **Acceptance hint:** значения переживают обычный reload и корректно проходят существующую нормализацию настроек.

- **Отказоустойчивость аудио:** ошибка загрузки или воспроизведения аудиофайла не должна останавливать игровой сценарий.
  - **Пояснение:** аудио остаётся дополнительным эффектом и не блокирует физику или управление.
  - **Источник:** требование воспроизводить выбираемые локальные звуки.
  - **Acceptance hint:** недоступный аудиофайл не вызывает необработанную ошибку и не блокирует последующие взаимодействия.

- **Понятный выбор звука:** названия вариантов в UI должны соответствовать файлам папки `gachi` и быть различимыми для пользователя.
  - **Пояснение:** пользователь должен понимать, какой звук выбран.
  - **Источник:** «выбрать один звук из папки gachi».
  - **Acceptance hint:** каждый поддерживаемый файл представлен одним вариантом списка.

## Проблемы и замечания, превращённые в требования

- **Камера прекращает слежение при падении:** сейчас camera-follow не продолжает плавное движение вниз. Требуемое поведение: управляемое через UI lerp-слежение за падающим камнем.
  - **Источник:** «Когда камень падает вниз продолжай следовать камерой за ним с lerp».
  - **Acceptance hint:** камера продолжает плавно сопровождать камень после смены движения с подъёма на падение.

- **Автоскролл верхней области остаётся активным:** сейчас верхний автоскролл может продолжаться после помещения камня в верхнюю область. Требуемое поведение: отдельное управление и гарантированная остановка при выключении или прекращении условия активации.
  - **Источник:** «сейчас когда камень вверху почему-то остается автоскролл».
  - **Acceptance hint:** выключенный автоскролл не запускается и не продолжает менять позицию страницы.

- **Нельзя выбрать конкретный gachi-звук:** сейчас пользователь не управляет звуком клика по камню. Требуемое поведение: выбор одного файла со значением по умолчанию `Camen.mp3`.
  - **Источник:** «дай на UI выбрать один звук из папки gachi».
  - **Acceptance hint:** изменение списка в UI определяет следующий звук клика по камню.

- **Смех срабатывает вне фейковых кликов:** сейчас область срабатывания `Смех.mp3` шире требуемой. Требуемое поведение: строго ограничить воспроизведение фейковыми кликами сцены 1.
  - **Источник:** «включай звук \"смех\" тольк при фейковых кликах».
  - **Acceptance hint:** все нефейковые события проходят без воспроизведения смеха.
