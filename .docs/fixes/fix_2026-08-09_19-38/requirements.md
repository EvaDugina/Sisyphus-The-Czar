## Исходный текст

1. Добавить в UI независимый выбор изображения основного камня и изображения камня в fold-зеркале.
2. Звук «Симуляция оргазма» должен проигрываться только при первом приземлении после касания камня рукой и не повторяться на последующих отскоках без нового касания рукой.
3. После каждого нового касания рукой звук снова разрешается один раз.
4. Отпечаток должен менять изображение вместе с основным камнем.
5. Для пульса нужна отдельная настройка уменьшения, независимая от уменьшения при нажатии.

## Функциональные требования

### Изображения камня

- **Выбор основного изображения:** Система должна позволять выбрать в UI изображение основного камня из доступного проекту каталога.
  - **Пояснение:** Пользователь управляет внешним видом камня без изменения исходного кода.
  - **Источник:** «добавь на ui выбор изображения для основного камня»
  - **Acceptance hint:** Выбрать каждый доступный вариант и убедиться, что основной камень сразу использует выбранное изображение.

- **Синхронизация отпечатка:** Система должна автоматически использовать выбранное основное изображение для отпечатка камня.
  - **Пояснение:** Основной камень и его отпечаток образуют одну визуальную пару.
  - **Источник:** «изображение отпечатка камня изменяй вместе с изменением основного изображения камня»
  - **Acceptance hint:** Сменить основное изображение и проверить `src` основного камня и отпечатка.

- **Выбор fold-изображения:** Система должна содержать отдельный UI-выбор изображения камня внутри fold-зеркала.
  - **Пояснение:** Fold получает собственный управляемый визуальный вариант.
  - **Источник:** «выбор изображения для отображаемого камня на fold-зеркале»
  - **Acceptance hint:** Выбрать для fold изображение, отличное от основного, и проверить обе области одновременно.

- **Независимость изображений:** Изменение основного изображения не должно менять fold-изображение, и наоборот.
  - **Пояснение:** Обе настройки являются самостоятельными.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Проверить все сочетания двух разных выбранных изображений.

- **Каталог и fallback:** Система должна принимать только изображения из разрешённого каталога и использовать текущие изображения по умолчанию для старых или некорректных настроек.
  - **Пояснение:** Старые сохранения остаются совместимыми, а UI не создаёт битые пути.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Загрузить настройки без новых полей и с неизвестным значением.

- **Сохранение выбора:** Обе настройки изображений должны входить в общую модель настроек, версии и production preset.
  - **Пояснение:** Выбор восстанавливается существующим механизмом сохранения.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Сохранить версию, загрузить её повторно и проверить оба изображения.

### Звук «Симуляция оргазма»

- **Взведение касанием:** Каждое новое успешное касание или захват камня рукой должно разрешать одно воспроизведение звука при следующем отдельном приземлении.
  - **Пояснение:** Новое касание рукой начинает новый одноразовый аудиоцикл.
  - **Источник:** «после каждого нового касания камня рукой звук снова разрешается один раз»
  - **Acceptance hint:** Дважды повторить цикл «касание рукой → приземление» и услышать по одному воспроизведению в каждом цикле.

- **Первое приземление:** Система должна проигрывать звук только при первом переходе камня из состояния вне земли в состояние контакта с землёй после касания рукой.
  - **Пояснение:** Удержание контакта с землёй и несколько кадров одного столкновения не считаются новыми приземлениями.
  - **Источник:** «звук ... должен включаться только при первом касании земли»
  - **Acceptance hint:** Проверить счётчик воспроизведений на первом контакте и последующих физических шагах.

- **Погашение и повторное взведение:** После воспроизведения система должна запретить звук до следующего нового касания рукой.
  - **Пояснение:** Последующие отскоки текущего движения не повторяют эффект.
  - **Источник:** «при дальнейших отскоках ... звук ... включаться не должен»
  - **Acceptance hint:** После первого приземления дождаться нескольких отскоков, затем снова коснуться камня рукой и проверить ровно одно новое воспроизведение.

- **Запрет без касания рукой:** Первоначальное падение, автоматическое движение и приземления без предшествующего касания рукой не должны запускать звук.
  - **Пояснение:** Случайный контакт с землёй сам по себе не взводит эффект.
  - **Источник:** «касании земли без касания рукой камня звук ... включаться не должен»
  - **Acceptance hint:** Дождаться приземления без пользовательского контакта и проверить отсутствие воспроизведения.

- **Касание лежащего камня:** Касание рукой камня на земле не должно немедленно запускать звук; оно должно разрешать звук для следующего отдельного приземления.
  - **Пояснение:** Аудиособытие привязано к переходу на землю, а не к самому нажатию.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Коснуться лежащего камня, не отрывая его от земли, и проверить отсутствие звука до следующего приземления.

- **Остальные аудиоэффекты:** Изменение не должно менять правила звука удара, смеха и других эффектов.
  - **Пояснение:** Исправляется только «Симуляция оргазма».
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Проверить существующие аудио smoke-тесты.

### Независимое уменьшение при пульсе

- **Новая настройка:** Система должна содержать отдельную настройку «Уменьшение при пульсе, %».
  - **Пояснение:** Глубина пульса управляется независимо от пользовательского нажатия.
  - **Источник:** «добавь для пульса отдельную переменную уменьшения»
  - **Acceptance hint:** Убедиться, что новый контрол присутствует в группе камня и доступен при включённом пульсе.

- **Разделение эффектов:** Настройка «Уменьшение при нажатии, %» должна управлять только нажатием, а новая настройка — только фазой сжатия пульса.
  - **Пояснение:** Изменение одного значения не влияет на другое.
  - **Источник:** «хочу задавать уменьшение при сжатии отдельно от уменьшения при пульсе»
  - **Acceptance hint:** Задать разные значения, например 5% и 20%, и измерить независимые масштабы обоих эффектов.

- **Нулевое значение:** Значение `0%` должно отключать уменьшение соответствующего эффекта.
  - **Пояснение:** Пользователь может оставить эффект активным без изменения размера.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Проверить оба параметра при нулевом значении.

- **UI-зависимость:** Настройка уменьшения при пульсе должна быть недоступна, когда пульс выключен, аналогично BPM.
  - **Пояснение:** Недействующий параметр визуально обозначается как недоступный.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Переключить пульс и проверить `disabled` нового контрола.

- **Применение и сохранение:** Новый процент должен применяться без перезагрузки, сохраняться в настройках, версиях и production preset и получать совместимый default при миграции старых данных.
  - **Пояснение:** Новое поле является полноправной частью общей модели настроек.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Изменить значение, проверить текущий пульс, сохранить и повторно загрузить версию.

- **Пересечение эффектов:** Если пульс и нажатие пересекаются, уменьшение при нажатии должно иметь приоритет; проценты не должны складываться или перемножаться.
  - **Пояснение:** Это утверждённая рабочая интерпретация поведения.
  - **Источник:** approved рабочая интерпретация
  - **Acceptance hint:** Инициировать нажатие во время пульса и проверить масштаб по параметру нажатия.

- **Диапазон нового параметра:** Диапазон и шаг уменьшения при пульсе должны совпадать с существующей настройкой уменьшения при нажатии.
  - **Пояснение:** Это утверждённая рабочая интерпретация UI.
  - **Источник:** approved рабочая интерпретация
  - **Acceptance hint:** Сравнить атрибуты `min`, `max` и `step` обоих контролов.

## Нефункциональные требования

- **Немедленное отображение:** Изображения и процент пульса должны применяться без заметной задержки и без обязательной перезагрузки.
  - **Пояснение:** Пользователь сразу видит результат настройки.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Изменять контролы на открытой странице и наблюдать текущую сцену.

- **Устойчивость fold:** Fold не должен возвращаться к устаревшему `src` после изменения настроек или Fast Refresh.
  - **Пояснение:** Fold-изображение управляется явно, а не остаётся случайным DOM-клоном.
  - **Источник:** замечание о fold-зеркале
  - **Acceptance hint:** Несколько раз сменить оба изображения и проверить fold после обновления интерфейса.

- **Доступность UI:** Новые элементы должны иметь понятные подписи, различающие основной камень, fold-камень и уменьшение при пульсе.
  - **Пояснение:** Назначение контролов должно читаться вспомогательными технологиями.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Проверить accessible name элементов управления.

- **Защита от повторного события:** Несколько кадров одного контакта с землёй не должны повторно запускать звук.
  - **Пояснение:** Аудиообработчик должен быть идемпотентным в рамках одного приземления.
  - **Источник:** требование однократного воспроизведения
  - **Acceptance hint:** Прогнать несколько физических шагов при лежащем камне и проверить неизменный счётчик.

- **Стабильность масштаба:** Пульс не должен накапливать уменьшение от цикла к циклу.
  - **Пояснение:** Масштаб рассчитывается от базового состояния.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Прогнать несколько периодов и сравнить минимальный масштаб каждого цикла.

- **Отсутствие регрессий:** Изменения не должны влиять на координаты, захват, физику и базовое масштабирование камня.
  - **Пояснение:** Новая визуальная конфигурация не меняет игровую механику.
  - **Источник:** утверждённый черновик требований
  - **Acceptance hint:** Прогнать релевантные unit- и smoke-тесты сцены.

## Проблемы и замечания, превращённые в требования

- **Неуправляемое fold-изображение:** Сейчас fold наследует `src` основного камня и может сохранять устаревшее изображение. Требуемое поведение: fold использует отдельную настройку из разрешённого каталога.
- **Повторный звук на отскоках:** Сейчас звук может повторяться при контактах с землёй. Требуемое поведение: не более одного воспроизведения на цикл «новое касание рукой → первое приземление».
- **Общее уменьшение масштаба:** Сейчас глубина пульса не имеет отдельной пользовательской настройки. Требуемое поведение: нажатие и пульс используют независимые параметры.
