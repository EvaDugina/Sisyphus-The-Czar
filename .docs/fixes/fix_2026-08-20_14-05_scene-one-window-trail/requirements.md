## Исходный текст

Для Сцены 1 пользователь просит после первого не фейкового клика показывать все свёрнутые окна, открытые фейковыми кликами; изменить диапазон ширины окон с картинками на `0.01–1` с шагом `0.01`, где `1` соответствует `100vw`, сохранив текущий расчёт высоты; добавить камню динамический след в виде дискретного многослойного эхо-шлейфа по приложенному визуальному референсу и вынести параметры следа в отдельную группу UI.

## Функциональные требования

- **Восстановление окон после настоящего клика:** После первого не фейкового клика система должна развернуть и показать все свёрнутые окна, открытые в результате фейковых кликов.
  - **Пояснение:** Финальное действие Сцены 1 должно возвращать на экран все относящиеся к фейковым кликам свёрнутые popup-окна.
  - **Источник:** "После первого не фейкового клика показывай все свернутые окна открытые при фейковых кликах".
  - **Acceptance hint:** Выполнить несколько фейковых кликов, свернуть появившиеся окна и сделать первый не фейковый клик — все соответствующие окна становятся видимыми.

- **Диапазон ширины окон с изображениями:** Ширина окна с картинкой должна задаваться значением от `0.01` до `1` включительно с шагом `0.01`; значение интерпретируется как доля ширины viewport.
  - **Пояснение:** `0.01` соответствует `1vw`, `0.5` — `50vw`, `1` — `100vw`; существующий способ расчёта высоты сохраняется.
  - **Источник:** "Изменяю диапазон: от 0.01 до 1, где 1 - это 100% по vw"; "Шаг 0.01"; "Сохранять текущий способ рассчета высоты".
  - **Acceptance hint:** UI и runtime принимают границы `0.01` и `1`, соседние значения различаются на `0.01`, а высота продолжает рассчитываться существующим способом.

- **Динамический эхо-след камня:** Во время перемещения камня система должна отображать следующие за ним копии его предыдущих состояний и позиций.
  - **Пояснение:** След повторяет фактическую траекторию камня, состоит из нескольких дискретных наложенных копий, образует ступенчатый шлейф по визуальному референсу, обновляется во время движения и прекращает создавать новые копии после остановки.
  - **Источник:** "След должен быть как на референсе из скриншота".
  - **Acceptance hint:** При движении камня виден многослойный эхо-шлейф из его прошлых позиций, а не сплошная линия или обычный particle-эффект.

- **Параметры следа в UI:** В интерфейсе настроек Сцены 1 должна появиться отдельная группа параметров «След камня».
  - **Пояснение:** Группа содержит включение следа, количество копий, интервал создания копий, прозрачность и длительность существования либо скорость исчезновения копий. Изменения применяются без перезапуска сцены.
  - **Источник:** "добавь для следа камня отдельные параметры на UI".
  - **Acceptance hint:** Все перечисленные настройки доступны в отдельной группе и непосредственно изменяют текущий визуальный эффект.

## Нефункциональные требования

- **Сохранение расчёта высоты:** Изменение модели ширины не должно менять существующий способ вычисления высоты окон.
  - **Пояснение:** Меняется только единица и диапазон управления шириной.
  - **Источник:** "Сохранять текущий способ рассчета высоты".
  - **Acceptance hint:** При одинаковом содержимом и ширине соотношение и алгоритм вычисления высоты совпадают с текущим поведением.

- **Визуальное соответствие:** След должен восприниматься как многослойное эхо движущегося камня, соответствующее предоставленному референсу.
  - **Пояснение:** Текст и интерфейс сайта на скриншоте не копируются; референс задаёт только характер ступенчатого шлейфа.
  - **Источник:** "След должен быть как на референсе из скриншота".
  - **Acceptance hint:** След состоит из визуально различимых последовательных копий камня вдоль его траектории.

- **Плавное обновление:** След должен обновляться согласованно с движением камня, без заметного отставания и случайных скачков.
  - **Пояснение:** Эхо-копии должны отражать реальные предыдущие позиции объекта.
  - **Источник:** "Добавь камню динамический след при перемещении".
  - **Acceptance hint:** При непрерывном движении последовательность копий остаётся связанной с траекторией камня.

- **Изоляция изменений:** Новое поведение должно применяться только к Сцене 1 и не менять остальные сцены.
  - **Пояснение:** Требования явно ограничены первой сценой.
  - **Источник:** "для СЦЕНЫ 1".
  - **Acceptance hint:** Сцены 2 и 3 сохраняют прежнее поведение окон, камня и интерфейса.

- **Совместимость управления:** Отображение следа не должно блокировать клики, перетаскивание или другие взаимодействия с камнем и интерфейсом.
  - **Пояснение:** Визуальные копии являются неинтерактивным слоем.
  - **Источник:** Требование динамического следа при перемещении камня.
  - **Acceptance hint:** Камень и UI остаются доступны для pointer-взаимодействий при включённом следе.

## Проблемы и замечания, превращённые в требования

- **Свёрнутые popup-окна остаются скрытыми:** Сейчас окна, появившиеся при фейковых кликах и затем свёрнутые, не возвращаются автоматически. Требуемое поведение: показать их после первого не фейкового клика.
  - **Источник:** "После первого не фейкового клика показывай все свернутые окна открытые при фейковых кликах".
  - **Acceptance hint:** Первый настоящий клик восстанавливает все соответствующие свёрнутые окна.

- **Диапазон ширины окон не соответствует требованию:** Сейчас управление шириной не использует требуемый диапазон и единицы. Требуемое поведение: ширина `1–100vw` с дискретностью `1vw`.
  - **Источник:** "от 0.01 до 1, где 1 - это 100% по vw"; "Шаг 0.01".
  - **Acceptance hint:** Значение `0.01` даёт `1vw`, а `1` — `100vw`.

- **У камня отсутствует требуемый эхо-след:** Сейчас перемещение камня не сопровождается настраиваемым ступенчатым шлейфом из прошлых позиций. Требуемое поведение: отображать и настраивать такой след в Сцене 1.
  - **Источник:** "Добавь камню динамический след при перемещении"; "След должен быть как на референсе из скриншота".
  - **Acceptance hint:** При включённом эффекте движение создаёт последовательность настраиваемых копий камня.
