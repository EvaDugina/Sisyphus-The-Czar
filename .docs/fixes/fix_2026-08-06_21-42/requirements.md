## Функциональные требования

- **Максимум parallax в `vw`:** Система должна хранить и показывать максимальное preclick parallax-смещение в `vw` в диапазоне `0–150` с шагом `0.1`.
  - **Пояснение:** Runtime переводит значение в пиксели относительно текущей ширины viewport; значение `0` отключает parallax-смещение.
  - **Источник:** «Сделай измерение максимального параллакс в vw от 0 до 150».
  - **Acceptance hint:** UI показывает суффикс `vw`; при resize одинаковое значение сохраняет пропорциональный viewport размер смещения.

- **Миграция максимума parallax:** Старое поле в `px` должно мигрировать в новое поле `vw` по фиксированному соотношению `20 px = 1 vw`.
  - **Пояснение:** Прежний default `12 px` становится новым default `0.6 vw`; миграция не зависит от устройства, на котором открыта настройка.
  - **Источник:** Одобренный default из черновика требований.
  - **Acceptance hint:** Старый payload со значением `12 px` после миграции содержит `0.6 vw`, а legacy-поле удалено.

- **Режим видимости руки:** В UI должен быть versioned checkbox «Показывать руку всегда».
  - **Пояснение:** Включённый флаг сохраняет постоянную руку по всей сцене; выключенный показывает руку только при hover камня и во время его захвата. Hover означает наведение именно на камень.
  - **Источник:** «Дай флаг на UI показывать руку всегда или только по hover».
  - **Acceptance hint:** Переключение применяется сразу, сохраняется после reload и синхронизируется через room settings; default — включено.

- **Статичная камера до первого клика:** После начального позиционирования сцены камера не должна менять вертикальную позицию до первого primary-click по камню.
  - **Пояснение:** Автоматический и ручной вертикальный scroll до активации заблокированы; движение указателя и parallax не двигают viewport.
  - **Источник:** «До первого клика по камню, камера статична и не двигается».
  - **Acceptance hint:** После завершения init значение `scrollY` остаётся неизменным при pointermove, wheel, touch-scroll и клавишах прокрутки до клика по камню.

- **Камень без физики до первого клика:** До первого primary-click по камню физическая симуляция должна оставаться приостановленной; разрешено только визуальное parallax-смещение.
  - **Источник:** «после первого клика камень приобретает физику».
  - **Acceptance hint:** До клика камень не падает, не получает скорость и не пишет физический trail.

- **Атомарная активация первым кликом:** Первый допустимый primary `pointerdown` по камню должен отключить preclick parallax и обнулить его offset, активировать физику камня и запустить вертикальное слежение камеры.
  - **Источник:** «после первого клика камень приобретает физику, параллакс выключается и камера прикрепляется».
  - **Acceptance hint:** Все три состояния меняются в одном пользовательском событии; остаточный parallax отсутствует.

- **Вертикальное слежение камеры:** После активации камера должна вычислять целевой `scrollY` по высоте визуального центра камня, удерживая его около `50%` высоты viewport, и ограничивать цель границами документа.
  - **Пояснение:** Фактический `scrollY` приближается к цели через lerp; горизонтальная камера не добавляется.
  - **Источник:** «камера прикрепляется по высоте к камню с lerp» и одобренный default из черновика.
  - **Acceptance hint:** При движении камня вверх и вниз камера следует за ним без мгновенного скачка и не выходит за границы документа.

- **Категория «Камера»:** В UI должна появиться отдельная категория «Камера» с range-контролом «Lerp камеры».
  - **Пояснение:** Диапазон `0.01–1`, шаг `0.01`, default `0.1`; `1` означает мгновенное следование, меньшие значения — более плавное и медленное.
  - **Источник:** «lerp на UI в категории камера» и одобренные defaults из черновика.
  - **Acceptance hint:** Изменение контрола сразу влияет на скорость приближения камеры к целевой высоте и сохраняется после reload.

- **Замена старой автопрокрутки:** Новый camera-follow должен заменить зонный алгоритм `positionScroll*`, чтобы механизмы не конкурировали за `window.scrollY`.
  - **Пояснение:** После первого клика camera-follow переопределяет ручной вертикальный scroll; старые `positionScroll*` не должны влиять на runtime.
  - **Источник:** Одобренное решение из черновика требований.
  - **Acceptance hint:** В одном animation frame существует только один источник программного изменения `scrollY`.

- **Сохранение и синхронизация:** Максимум parallax в `vw`, режим видимости руки и camera lerp должны входить в versioned local settings, room settings, серверные шаблоны и production preset.
  - **Источник:** Одобренный контракт черновика.
  - **Acceptance hint:** Значения проходят sanitizer, snapshot, save/load, broadcast и legacy migration.

## Нефункциональные требования

- **Адаптивность:** Расчёт parallax в `vw` должен обновляться при resize без деформации камня.
  - **Пояснение:** Меняется только позиционный offset.
  - **Источник:** Переход единицы измерения в `vw`.
  - **Acceptance hint:** Размеры камня до и после parallax совпадают, offset масштабируется вместе с viewport.

- **Плавный переход:** Первый клик не должен вызывать остаточный parallax или резкий скачок камеры.
  - **Пояснение:** Camera-follow начинает интерполяцию от текущего `scrollY`.
  - **Источник:** Требование camera lerp после первого клика.
  - **Acceptance hint:** Первый кадр после активации начинается с текущего положения камеры, дальнейшие кадры монотонно приближаются к цели.

- **Совместимость:** Legacy settings должны получать детерминированную миграцию и безопасные defaults.
  - **Источник:** Изменение versioned схемы настроек.
  - **Acceptance hint:** Старые local/server payload загружаются без ошибки и нормализуются к новой схеме.

- **Устройства ввода:** Фото-рука и hover-режим должны применяться только к fine pointer; touch не должен получать искусственный hover.
  - **Источник:** Существующий fine-pointer контракт, сохранённый в одобренном черновике.
  - **Acceptance hint:** Touch-сценарий не показывает постоянную фото-руку и остаётся управляемым.

- **Регрессионная безопасность:** Изменения не должны нарушать drag/release, obstacle blocking, Fold, trail и single-client session contracts.
  - **Источник:** Одобренное ограничение черновика.
  - **Acceptance hint:** Релевантные unit/integration и browser smoke проходят.

## Проблемы и замечания, превращённые в требования

- **Абсолютная единица максимума:** Сейчас максимум parallax хранится в `px`. Требуемое поведение: пропорциональное viewport смещение в `vw` с диапазоном `0–150`.
  - **Источник:** «Сделай измерение максимального параллакс в vw от 0 до 150».
  - **Acceptance hint:** В актуальной схеме и UI нет рабочего поля максимума parallax в `px`.

- **Обязательная постоянная рука:** Сейчас постоянная рука включена без пользовательского выбора. Требуемое поведение: versioned UI-флаг переключает постоянный и hover-only режимы.
  - **Источник:** «Дай флаг на UI показывать руку всегда или только по hover».
  - **Acceptance hint:** Оба режима проверяются browser smoke.

- **Зонная автопрокрутка:** Сейчас `positionScroll*` двигает viewport по краевым зонам. Требуемое поведение: до активации камера заблокирована, после активации напрямую следует за высотой камня через lerp.
  - **Источник:** «камера статична… камера прикрепляется по высоте к камню с lerp».
  - **Acceptance hint:** Старый зонный алгоритм больше не вызывается runtime и не представлен как действующий UI-контракт.
