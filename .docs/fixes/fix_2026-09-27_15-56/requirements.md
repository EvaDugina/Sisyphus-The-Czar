## Функциональные требования

- **Раздельный выбор звуков:** В UI сцены 1 должны оставаться два независимых списка: «Звук фейкового клика» и «Звук отскакивания».
  - **Пояснение:** Пользователь должен отдельно настраивать звук каждого типа события.
  - **Источник:** «Для фейкового клика и для отскакивания нужна возможность на UI выбирать разные звуки».
  - **Acceptance hint:** Изменение одного списка не изменяет значение второго.

- **Единый набор вариантов:** Оба списка должны содержать отключение звука, «Смех», «Симуляция оргазма» и все поддерживаемые звуки из папки `gachi`.
  - **Пояснение:** Набор доступных звуков должен быть одинаковым для обоих типов события.
  - **Источник:** «Добавь возможность для звука фейкового клика выбрать звуки между Симмуляцией оргазма и Смех и звуками из папки gachi».
  - **Acceptance hint:** Оба списка показывают одинаковый полный набор поддерживаемых вариантов.

- **Значения по умолчанию:** Для фейкового клика по умолчанию должна быть выбрана «Симуляция оргазма», для отскакивания — «Смех».
  - **Пояснение:** Значения должны применяться к новой или мигрированной конфигурации без явного выбора пользователя.
  - **Источник:** «Звук отскакивания по умолчанию смех. Звук фейкового клика по умолчанию Симмуляция оргазма».
  - **Acceptance hint:** После загрузки конфигурации без этих полей UI и runtime используют утверждённые значения по умолчанию.

- **Звук фейкового клика:** При зарегистрированном фейковом клике выбранный звук фейкового клика должен воспроизводиться ровно один раз.
  - **Пояснение:** Фейковый клик имеет собственный звуковой канал.
  - **Источник:** «должен только звук фейкового клика».
  - **Acceptance hint:** Один фейковый клик увеличивает число воспроизведений выбранного звука фейкового клика на один.

- **Подавление звука вызванного отскока:** Если фейковый клик одновременно вызывает отскок камня, звук отскакивания для этого отскока не должен воспроизводиться.
  - **Пояснение:** В этом составном событии пользователь должен слышать только звук фейкового клика.
  - **Источник:** «Сейчас при отскакивании после фейкового клика играет два звука, а должен только звук фейкового клика».
  - **Acceptance hint:** При фейковом клике с отскоком счётчик звука фейкового клика увеличивается на один, а счётчик звука отскакивания не изменяется.

- **Звук обычного отскока:** При отскоке, не вызванном фейковым кликом, выбранный звук отскакивания должен воспроизводиться ровно один раз.
  - **Пояснение:** Новое правило не отключает звуковое сопровождение обычных отскоков.
  - **Источник:** «для отскакивания нужна возможность на UI выбирать разные звуки».
  - **Acceptance hint:** Обычный отскок увеличивает число воспроизведений выбранного звука отскакивания на один и не запускает звук фейкового клика.

- **Независимое сохранение:** Выборы звука фейкового клика и звука отскакивания должны сохраняться и загружаться независимо.
  - **Пояснение:** Последняя конфигурация должна полностью восстанавливать оба значения.
  - **Источник:** Утверждённое требование о двух независимых настройках.
  - **Acceptance hint:** После сохранения и повторной загрузки каждое поле восстанавливает своё значение.

## Нефункциональные требования

- **Отсутствие наложения:** Одно действие фейкового клика не должно создавать наложение звука фейкового клика и звука вызванного им отскока.
  - **Пояснение:** Составное событие должно иметь один ожидаемый звуковой отклик.
  - **Источник:** «играет два звука, а должен только звук фейкового клика».
  - **Acceptance hint:** Воспроизводится один выбранный файл звука фейкового клика.

- **Локальность изменения:** Новое правило не должно менять стартовый клик, другие сцены, условия возникновения фейковых кликов и механику движения камня.
  - **Пояснение:** Исправляется только маршрутизация звука составного события сцены 1.
  - **Источник:** Контекст уточнения относится только к отскоку после фейкового клика.
  - **Acceptance hint:** Существующие проверки движения, завершения сцены и остальных сцен продолжают проходить.

## Проблемы и замечания, превращённые в требования

- **Двойной звук после фейкового клика:** Сейчас отскок, вызванный фейковым кликом, запускает два звука. Требуемое поведение: воспроизводить только выбранный звук фейкового клика и подавлять звук отскакивания для этого конкретного отскока.
  - **Источник:** «Сейчас при отскакивании после фейкового клика играет два звука, а должен только звук фейкового клика».
  - **Acceptance hint:** Для каждого из первых двух и третьего фейковых кликов звук отскакивания не запускается, а звук фейкового клика запускается один раз.
