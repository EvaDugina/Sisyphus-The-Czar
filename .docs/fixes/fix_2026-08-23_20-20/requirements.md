## Исходный текст

Для сцены 1 требуется: добавить в UI выбор звука фейкового клика, включая вариант без звука; исправить неработающий пульс; переименовать режим картин «Случайно циклично» в «Циклично»; на первом настоящем клике после всех фейковых создать новое popup-окно и одновременно показать ранее всплывшие окна; после настоящего клика оставить руку сжимающей камень.

## Функциональные требования

- **Выбор звука фейкового клика:** Система должна показывать в настройках сцены 1 select-контрол «Звук фейкового клика» с вариантами `Без звука`, `Смех.mp3` и существующими gachi-звуками. Значение по умолчанию — `Смех.mp3`.
  - **Пояснение:** Выбранный звук воспроизводится при каждом засчитанном фейковом клике; вариант `Без звука` отключает создание и запуск аудио, не меняя логику клика.
  - **Источник:** «Дай на UI возможность выбирать звук для фейкового клика»; «Добавь также вариант без звука».
  - **Acceptance hint:** Выбрать разные файлы и подтвердить их воспроизведение; выбрать `Без звука` и подтвердить отсутствие аудио при сохранении отскока камня.

- **Сохранение выбранного звука:** Система должна сохранять настройку звука фейкового клика так же, как остальные параметры сцены 1, включая локальный снимок, шаблон и production preset. Старые настройки без нового поля должны использовать `Смех.mp3`.
  - **Пояснение:** Новый параметр не должен ломать ранее сохранённые конфигурации.
  - **Источник:** Требование выбора звука через существующий UI настроек.
  - **Acceptance hint:** Выбор сохраняется после перезагрузки; старый snapshot мигрирует со значением `Смех.mp3`.

- **Рабочий пульс камня в сцене 1:** При включённой настройке пульса система должна циклически менять масштаб камня в сцене 1 с указанными BPM и процентом сжатия. Работа пульса не должна зависеть от состояния, предназначенного только для сцены 2.
  - **Пояснение:** Анимация должна быть видна в активном сценарии сцены 1 до настоящего клика.
  - **Источник:** «Пульс не работает!».
  - **Acceptance hint:** До настоящего клика включить пульс и подтвердить периодическое изменение масштаба; выключение возвращает постоянный масштаб.

- **Переименование режима картин:** Система должна отображать для циклического режима подпись `Циклично` вместо `Случайно циклично`, не меняя логику строгого последовательного цикла картин.
  - **Пояснение:** Меняется только пользовательская подпись существующего режима.
  - **Источник:** «Переименуй \"случайно циклично\" в \"циклично\"».
  - **Acceptance hint:** Select показывает `Циклично`, а последовательность картин остаётся циклической.

- **Дополнительный popup на настоящем клике:** Первый настоящий клик после исчерпания фейковых кликов должен немедленно создать ещё одно popup-окно с картиной и одновременно показать или вывести на передний план все ранее созданные и ещё не закрытые popup-окна, включая окна, ожидавшие настроенную задержку.
  - **Пояснение:** Новая картина выбирается по текущему случайному, цикличному или фиксированному режиму; размер соответствует настройке ширины popup сцены 1. Вручную закрытые окна повторно не открываются.
  - **Источник:** «На настоящем клике после всех фейковых отрисовывай новое всплывающее окно вместе с показом уже всплывших».
  - **Acceptance hint:** После N фейковых кликов настоящий клик увеличивает число созданных окон ещё на одно и раскрывает все живые окна.

- **Захват камня рукой после настоящего клика:** После первого настоящего клика фото-рука должна перейти в состояние сжатия камня и оставаться в нём после отпускания кнопки указателя до перезапуска сцены.
  - **Пояснение:** Финальное состояние сцены 1 должно визуально сохранять захват камня.
  - **Источник:** «После настоящего клика оставляй руку сжимающей камень».
  - **Acceptance hint:** После `pointerdown` и `pointerup` рука продолжает отображаться спрайтом захвата; «Начать сначала» возвращает исходное состояние.

## Нефункциональные требования

- **Совместимость настроек:** Система должна продолжать загружать существующие сохранённые шаблоны и пользовательские настройки без ошибок.
  - **Пояснение:** Отсутствующий новый параметр получает совместимое значение по умолчанию.
  - **Источник:** Новая сохраняемая настройка звука.
  - **Acceptance hint:** Проверить миграцию предыдущей версии settings schema.

- **Изоляция сцен:** Изменения пульса, popup и состояния руки не должны менять поведение сцен 2 и 3.
  - **Пояснение:** Требования ограничены сценой 1.
  - **Источник:** Все исходные замечания явно относятся к сцене 1.
  - **Acceptance hint:** Релевантные существующие проверки сцен 2 и 3 остаются зелёными.

- **Устойчивость аудио:** Ошибка воспроизведения выбранного файла не должна прерывать фейковый клик или движение камня.
  - **Пояснение:** Аудио остаётся побочным визуально-звуковым эффектом.
  - **Источник:** Требование выбора звука фейкового клика.
  - **Acceptance hint:** Отклонённый `Audio.play()` не приводит к ошибке основного сценария.

## Проблемы и замечания, превращённые в требования

- **Пульс сцены 1:** Сейчас анимация допускается только при специальном состоянии сцены 2. Требуемое поведение: независимая работа пульса в сцене 1 при включённой настройке.
  - **Источник:** «Пульс не работает!».
  - **Acceptance hint:** Test API показывает изменяющийся коэффициент пульса в сцене 1.

- **Фото-рука на настоящем клике:** Сейчас grabbing включается для курсора, но сжимающий спрайт фото-руки не закрепляется. Требуемое поведение: устойчивый визуальный захват после настоящего клика.
  - **Источник:** «После настоящего клика оставляй руку сжимающей камень».
  - **Acceptance hint:** CSS-состояние сжимающей руки сохраняется после `pointerup`.

- **Финальный popup:** Сейчас настоящий клик раскрывает существующие окна, но не создаёт дополнительное. Требуемое поведение: создать новое окно и раскрыть существующие одним действием.
  - **Источник:** «На настоящем клике после всех фейковых отрисовывай новое всплывающее окно вместе с показом уже всплывших».
  - **Acceptance hint:** Финальный настоящий клик создаёт ровно одно дополнительное окно.
