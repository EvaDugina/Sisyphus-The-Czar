## Исходный текст

Добавить в UI общий раздел «Курсор» с флагом «Показывать курсор» и настройкой размера. При выключенном флаге сохранить текущее поведение. При включённом одновременно с фото-рукой отображать SVG из `assets/cursor`: `handopen.svg` в обычном состоянии и `handgrabbing.svg` при захвате. Настройки едины для всех пользователей и сборок, входят в Git-синхронизируемые конфигурации. В production изменения применяются только после обновления страницы; live-обновление активных production-клиентов не требуется.

## Функциональные требования

- **Раздел «Курсор»:** Общий UI настроек должен содержать самостоятельный раздел «Курсор».
  - **Источник:** "Добавь на UI раздел \"курсор\""
  - **Acceptance hint:** Раздел присутствует в общем каталоге settings UI.

- **Переключатель отображения:** Раздел должен содержать checkbox «Показывать курсор» с default `выключено`.
  - **Источник:** "добавь галочку \"показывать курсор\""
  - **Acceptance hint:** Новая и мигрированная конфигурация не показывает SVG до включения флага.

- **Настройка размера:** Раздел должен содержать range «Размер курсора, px» с диапазоном `8–128`, шагом `1` и default `32`.
  - **Источник:** "Настройку размера svg вынеси а UI"
  - **Acceptance hint:** Изменение поля обновляет ширину и высоту обоих SVG с сохранением пропорций.

- **Зависимость размера:** Поле размера остаётся видимым, но получает native `disabled`, когда отображение курсора выключено; сохранённое значение не сбрасывается.
  - **Acceptance hint:** Выключение и повторное включение флага восстанавливает прежний размер.

- **Обратная совместимость:** При выключенном флаге SVG отсутствует, а фото-рука и нативный курсор работают как до изменения.
  - **Источник:** "Если это поле выключено, то курсор отображается как сейчас"

- **Одновременное отображение:** При включённом флаге SVG отображается одновременно с фото-рукой, не заменяя её.
  - **Источник:** "кроме руки отображается должен отображаться курсоры"

- **Состояния ассета:** Обычное состояние использует `assets/cursor/handopen.svg`, состояние `grabbing` — `assets/cursor/handgrabbing.svg`.
  - **Acceptance hint:** `pointerdown`/захват переключает SVG, `pointerup`/`pointercancel`/blur/принудительное отпускание возвращает открытое состояние.

- **Позиция и видимость:** SVG следует за соответствующим локальным или remote pointer и повторяет правила видимости руки. В native-cursor зонах settings и `session-panel--toolbar` локальный SVG скрывается.

- **Общая versioned-конфигурация:** Флаг и размер входят в общую room-settings schema; локальное переопределение не допускается.
  - **Источник:** "настройки распространяются на всех. одни настройки у всех пользователей"

- **Dev/debug-применение:** В dev и debug-production изменение флага или размера сразу применяется через существующий settings flow.

- **Production-применение:** Открытая slim-production страница сохраняет загруженную конфигурацию; обновлённый production preset применяется после reload страницы.
  - **Источник:** "На продакшене конфигурация применяется только при обновлении страницы"

- **Конфигурационные снимки:** Оба значения входят в черновик, именованные версии, общий каталог шаблонов, операцию сохранения версии/комнаты и production preset.

- **Git-синхронизация:** Новые значения хранятся в отслеживаемых `config/settings-templates.json` и `config/production-preset.json` и синхронизируются внешними Git-операциями.
  - **Источник:** "Конфигурации настроек синхронизируются через git"

- **Миграция:** Старые конфигурации без новых полей получают `Показывать курсор = false` и `Размер курсора = 32`.

## Нефункциональные требования

- **Единый контракт:** Клиент, сервер, шаблоны и production preset используют одинаковые ключи, defaults, limits и sanitization.
- **Версионирование:** Изменение сопровождается увеличением применимых schema versions и безопасной миграцией.
- **Безопасность взаимодействия:** SVG имеет `pointer-events: none` и не перекрывает UI или камень.
- **Совместимость устройств:** SVG отображается только при `fine pointer`; touch-поведение не меняется.
- **Стабильность:** Изменение отображения или размера не влияет на физику, положение камня и восстановление сессии.
- **Производительность:** SVG использует существующий pointer lifecycle без отдельного animation loop.
- **Сборка:** Оба SVG входят в dev и production bundle и не используют внешние ресурсы.
- **Production consistency:** В рамках одной загрузки production-конфигурация остаётся стабильной; live-обновление активных production-клиентов не требуется.
- **Контроль Git:** Приложение не выполняет `git commit`, `pull` или `push` самостоятельно.

## Проблемы и замечания, превращённые в требования

- **Отсутствие дополнительного курсора:** Сейчас существует только фото-рука или нативный системный курсор. Требуемое поведение: общая настройка включает дополнительный SVG одновременно с рукой.
- **Фиксированный размер ассета:** Сейчас пользователь не управляет размером SVG. Требуемое поведение: общий размер настраивается через UI и сохраняется во всех конфигурационных снимках.
- **Расхождение конфигураций:** Настройки не должны зависеть от localStorage конкретного браузера; источником являются общая room-конфигурация и production preset.
- **Production live-update:** Отсутствие live-применения новой конфигурации к уже открытой slim-production странице не является дефектом до reload.
