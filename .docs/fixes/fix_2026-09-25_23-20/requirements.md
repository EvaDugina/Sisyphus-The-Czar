## Исходный текст

Пользователь потребовал изменить вероятность подпускания для второго фейкового клика на 20%, сохранив существующие два обязательных отскока до начала вероятностного подпускания. При загрузке или перезагрузке страницы должна применяться последняя сохранённая конфигурация, а не локальный несохранённый черновик.

## Функциональные требования

- **Два обязательных отскока:** До включения вероятностного подпускания камень должен выполнить два обязательных отскока по существующей логике.
  - **Пояснение:** Изменение процента не должно менять подготовительную последовательность поведения камня.
  - **Источник:** "процент подпускания начинается не сразу, а как бы через 2 отскока"
  - **Acceptance hint:** До двух завершённых обязательных отскоков случайное значение не разрешает второй фейковый клик.

- **Вероятность подпускания 20%:** После двух обязательных отскоков каждая предусмотренная текущей механикой попытка приближения должна давать 20% вероятности подпускания курсора для второго фейкового клика.
  - **Пояснение:** Меняется только числовое значение вероятности с 10% на 20%.
  - **Источник:** "Нужно просто изменить процент на 20"
  - **Acceptance hint:** Случайное значение ниже 20% разрешает второй фейковый клик; значение от 20% включительно вызывает предусмотренный отскок.

- **Сохранение текущей последовательности:** Количество обязательных отскоков, порядок фейковых кликов, завершение сцены после третьего фейкового клика и остальные условия механики должны остаться без изменений.
  - **Пояснение:** Правка ограничена одним процентным значением.
  - **Источник:** "Нужно просто изменить процент на 20"
  - **Acceptance hint:** Регрессионный сценарий подтверждает два обязательных отскока и прежнее завершение сцены после третьего фейкового клика.

- **Загрузка последней конфигурации:** При первоначальной загрузке и перезагрузке страницы система должна автоматически применять последнюю сохранённую конфигурацию текущей сцены.
  - **Пояснение:** Последняя конфигурация определяется по наиболее позднему времени обновления.
  - **Источник:** "При загрузке страницы загружай последнюю конфигурацию"
  - **Acceptance hint:** При наличии нескольких конфигураций элементы управления и игровое состояние получают значения записи с самым поздним `updatedAt`.

- **Приоритет сохранённой конфигурации:** Локальный несохранённый черновик не должен применяться поверх последней сохранённой конфигурации при загрузке страницы.
  - **Пояснение:** Черновик может оставаться в локальном хранилище, но не является стартовым состоянием при наличии сохранённой конфигурации.
  - **Источник:** "а не черновик"
  - **Acceptance hint:** После перезагрузки значения соответствуют последней сохранённой конфигурации, даже если локально остались отличающиеся несохранённые значения.

- **Fallback при отсутствии конфигураций:** Если сохранённых конфигураций для сцены нет, система должна использовать стандартные настройки сцены.
  - **Пояснение:** Пустой каталог не должен блокировать запуск страницы.
  - **Источник:** "При загрузке страницы загружай последнюю конфигурацию"
  - **Acceptance hint:** При пустом каталоге страница запускается со стандартными настройками без ошибки.

## Нефункциональные требования

- **Предсказуемая инициализация:** Пользователь не должен видеть промежуточное применение черновика перед загрузкой последней конфигурации.
  - **Пояснение:** Стартовое состояние должно быть однозначным и не мигать между разными наборами параметров.
  - **Источник:** "При загрузке страницы загружай последнюю конфигурацию (а не черновик)"
  - **Acceptance hint:** После готовности страницы UI и runtime согласованы с одной последней сохранённой конфигурацией.

- **Совместимость:** Существующие сохранённые конфигурации должны продолжать корректно загружаться.
  - **Пояснение:** Правка не должна повреждать каталог версий и выбор сохранённых конфигураций.
  - **Источник:** "При загрузке страницы загружай последнюю конфигурацию"
  - **Acceptance hint:** Ранее сохранённые записи проходят текущую нормализацию и доступны в списке конфигураций.

## Проблемы и замечания, превращённые в требования

- **Недостаточная вероятность подпускания:** Сейчас после двух обязательных отскоков вероятность подпускания для второго фейкового клика составляет 10%. Требуемое поведение: вероятность составляет 20% при неизменной последовательности отскоков.
  - **Источник:** "Сделай для второго фейкового клика вероятность подпускания 20%"
  - **Acceptance hint:** Граница случайного решения изменена с `0.10` на `0.20`, а ветки обязательных отскоков не изменены.

- **Загрузка черновика вместо конфигурации:** Сейчас при старте может применяться локальный несохранённый черновик, а последняя конфигурация назначается базовой без применения к игровому состоянию. Требуемое поведение: последняя сохранённая конфигурация применяется как стартовое состояние.
  - **Источник:** "При загрузке страницы загружай последнюю конфигурацию (а не черновик)"
  - **Acceptance hint:** После получения каталога последняя запись применяется к контролам и runtime, не оставаясь только метаданными выбранной версии.
