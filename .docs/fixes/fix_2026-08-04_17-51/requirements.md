## Исходный текст

Пользователь сообщил, что камень не выпрыгивает вверх. Один раз за настроенный интервал на камень должна воздействовать сила, выбивающая его из руки. Существующие высота, скорость и характер движения должны быть сохранены. Направление вылета требуется выбирать в симметричном угловом секторе от 0° до 180°, а разброс прикладываемой силы — настраивать через UI.

---

## Функциональные требования

- **Периодическое выбивание камня:** Когда механика включена, система должна один раз за настроенный интервал прикладывать к камню силу, выбивающую его из руки.
  - **Пояснение:** Используется существующая настройка интервала.
  - **Источник:** "Раз в интервал на него должна … воздействовать сила, которая выбивает камень из руки".
  - **Acceptance hint:** При включённой механике камень покидает руку после истечения каждого настроенного интервала.

- **Сохранение существующей механики:** Базовые высота, скорость и характер вылета должны соответствовать уже предусмотренной игровой механике.
  - **Пояснение:** Исправление восстанавливает задуманное движение, не заменяя его новой моделью.
  - **Источник:** "Должны соответствовать, просто сейчас камень не выпрыгивает вверх".
  - **Acceptance hint:** Исправление использует существующие параметры движения камня.

- **Случайное направление вылета:** При каждом срабатывании система должна выбирать направление силы внутри настроенного углового сектора.
  - **Пояснение:** Сектор располагается симметрично относительно вертикального направления вверх.
  - **Источник:** "камень вылетал в любую сторону".
  - **Acceptance hint:** Повторные срабатывания выбирают направления в пределах настроенного сектора.

- **Настройка углового разброса:** UI должен предоставлять настройку углового разброса от 0° до 180°.
  - **Пояснение:** Значение обозначает полную ширину сектора, симметрично распределённого влево и вправо от вертикали. При 0° камень летит строго вверх; при 180° направление выбирается по всей верхней полуплоскости.
  - **Источник:** "создай на UI разброс в углах от 0 до 180 симметрично".
  - **Acceptance hint:** Увеличение настройки расширяет возможные направления одинаково в обе стороны.

- **Настройка разброса силы:** UI должен позволять задавать разброс величины прикладываемой силы относительно её существующего базового значения.
  - **Пояснение:** При каждом срабатывании величина импульса выбирается случайно внутри настроенного симметричного диапазона.
  - **Источник:** "дай настроить разброс применяемой силы на UI".
  - **Acceptance hint:** При нулевом разбросе используется базовая сила, при ненулевом — сила варьируется в пределах выбранного диапазона.

- **Совместная работа настроек:** Включение механики, интервал, угловой разброс и разброс силы должны совместно определять периодическое выбивание камня.
  - **Пояснение:** Все настройки относятся к одной механике и применяются при очередном срабатывании.
  - **Источник:** "Раз в интервал … создай на UI разброс … и дай настроить разброс применяемой силы".
  - **Acceptance hint:** Изменение каждой настройки отражается на следующем срабатывании механики.

## Нефункциональные требования

- **Понятность настроек:** UI должен показывать текущие числовые значения углового разброса и разброса силы рядом с соответствующими элементами управления.
  - **Пояснение:** Пользователь должен видеть выбранные значения до срабатывания механики.
  - **Источник:** "создай на UI разброс … и дай настроить разброс … на UI".
  - **Acceptance hint:** Числовые значения видимы и обновляются при изменении элементов управления.

## Проблемы и замечания, превращённые в требования

- **Камень не покидает руку:** Сейчас периодическая сила не обеспечивает вылет камня вверх. Требуемое поведение: при срабатывании камень физически отделяется от руки и движется в выбранном направлении.
  - **Источник:** "камень не выпрыгивает вверх".
  - **Acceptance hint:** После срабатывания камень перестаёт удерживаться рукой и получает видимое движение.

- **Фиксированное направление:** Текущее поведение предполагает только направление вверх. Требуемое поведение: направление варьируется внутри настраиваемого симметричного сектора.
  - **Источник:** "камень вылетал в любую сторону".
  - **Acceptance hint:** При ненулевом угловом разбросе камень может отклоняться в обе стороны от вертикали.
