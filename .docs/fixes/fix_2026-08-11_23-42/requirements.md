## Функциональные требования

- **Настраиваемая задержка popup:** После фейкового клика система должна показывать popup через настраиваемую задержку.
  - **Пояснение:** Значение по умолчанию — `200 мс`. На UI должен быть параметр «Задержка всплывающего окна, мс» с диапазоном `0–1000 мс`; значение `0` означает показ без задержки.
  - **Источник:** «пусть окно всплывает после фейкового клика через 200 ms (добавь это параметр на UI от 0 до 1000ms)»
  - **Acceptance hint:** При значении `200` окно становится видимым примерно через 200 мс после фейкового клика; граничные значения `0` и `1000` сохраняются и применяются.

- **Изображение камня в popup:** Popup, открытый после фейкового клика, должен отображать `assets/rock/rock.webp`.
  - **Пояснение:** Изображение занимает доступную область окна без искажения пропорций.
  - **Источник:** «Во всплывающем окне помести фото rock.webp»
  - **Acceptance hint:** В открывшемся окне виден `rock.webp`, изображение не растянуто и не обрезано.

- **Пропорции popup:** Соотношение ширины и высоты popup должно определяться фактическими пропорциями `rock.webp`, а не текущими размерами камня на сцене.
  - **Пояснение:** Визуальные трансформации камня в сцене 1 не должны менять геометрию изображения в popup.
  - **Источник:** «всплывающее окно открывай в пропорциях rock.webp»
  - **Acceptance hint:** Изменение визуального масштаба камня на сцене не изменяет соотношение сторон popup.

- **Размер popup:** Ширина popup должна вычисляться из существующего параметра «Размер после запуска физики, %» как доля ширины текущего viewport; высота должна рассчитываться по пропорциям `rock.webp`.
  - **Пояснение:** Если рассчитанный размер не помещается в доступную область экрана, окно пропорционально уменьшается.
  - **Источник:** «возьми размер для него из параметра \"размер камня после физики\"»
  - **Acceptance hint:** Изменение `rockActivatedWidthVw` меняет ширину следующего popup; пропорции изображения сохраняются.

- **Сохранение открытых popup:** Приложение не должно автоматически закрывать окна, созданные фейковыми кликами, ни по таймеру, ни по клику внутри окна, ни при переходе между сценами.
  - **Пояснение:** Закрыть такое окно пользователь может стандартными средствами браузера.
  - **Источник:** «Не закрывай автоматически открытые окна»
  - **Acceptance hint:** Popup остаётся открытым дольше текущих 2 секунд и не закрывается при клике по изображению.

- **Смех при каждом отскоке:** В сцене 1 каждый фактически начавшийся отскок камня должен один раз запускать `assets/audio/Смех.mp3`.
  - **Пояснение:** Требование относится к автоматическим отскокам от приближения курсора и отскокам от фейковых кликов. Если отскок пропущен по настроенной вероятности, звук не запускается.
  - **Источник:** «Верни звук Смех после каждого отпрыгивания»
  - **Acceptance hint:** Количество запусков смеха совпадает с количеством реально выполненных отскоков.

- **Camen при фейковом клике:** Каждый принятый фейковый клик в сцене 1 должен один раз запускать `assets/audio/gachi/Camen.mp3`, независимо от звука смеха и результата открытия popup.
  - **Пояснение:** Фейковый клик запускает оба звука, автоматический отскок без клика — только смех.
  - **Источник:** «При фейковом клике включай звук Camen»
  - **Acceptance hint:** При фейковом клике запускаются `Camen.mp3` и `Смех.mp3`; при автоматическом отскоке запускается только `Смех.mp3`.

## Нефункциональные требования

- **Сохранение настройки:** Задержка popup должна проходить через существующую модель настроек, нормализоваться в диапазоне `0–1000 мс` и сохраняться тем же способом, что остальные настройки сцены.
  - **Пояснение:** Значение должно работать после сохранения и повторной загрузки настроек.
  - **Источник:** «добавь это параметр на UI от 0 до 1000ms»
  - **Acceptance hint:** Сохранённая задержка восстанавливается после reload и остаётся в допустимом диапазоне.

- **Независимость эффектов:** Блокировка popup браузером или ошибка воспроизведения одного аудиофайла не должна отменять отскок либо запуск другого звука.
  - **Пояснение:** Визуальные, звуковые и popup-эффекты одного события должны отрабатывать независимо.
  - **Источник:** Совокупность требований к одному фейковому клику.
  - **Acceptance hint:** При заблокированном popup камень продолжает отпрыгивать, а разрешённые аудиособытия запускаются.

- **Параллельное аудио:** Повторные события не должны принудительно обрывать уже запущенные экземпляры `Смех.mp3` или `Camen.mp3`.
  - **Пояснение:** Каждый реальный отскок и каждый фейковый клик имеют собственный звуковой экземпляр.
  - **Источник:** «после каждого отпрыгивания» и «при фейковом клике».
  - **Acceptance hint:** Быстрые последовательные события могут звучать одновременно и доигрывают естественно.

## Проблемы и замечания, превращённые в требования

- **Пустое popup-окно:** Сейчас popup не содержит изображения. Требуемое поведение: показывать в нём `rock.webp` без искажения пропорций.
  - **Источник:** «Во всплывающем окне помести фото rock.webp»
  - **Acceptance hint:** В popup отображается требуемый файл.

- **Автоматическое закрытие popup:** Сейчас popup закрывается через 2 секунды и при клике внутри. Требуемое поведение: приложение не закрывает popup фейкового клика автоматически.
  - **Источник:** «Не закрывай автоматически открытые окна»
  - **Acceptance hint:** Окно остаётся открытым до ручного закрытия средствами браузера.

- **Фиксированная и контекстная геометрия:** Сейчас ширина popup зафиксирована на `640 px`, а пропорции берутся из текущего DOM-размера камня. Требуемое поведение: размер берётся из `rockActivatedWidthVw`, пропорции — из исходного `rock.webp`.
  - **Источник:** «всплывающее окно открывай в пропорциях rock.webp и возьми размер для него из параметра \"размер камня после физики\"»
  - **Acceptance hint:** Геометрия соответствует настройке и исходному изображению.

- **Отсутствующий смех при автоматических отскоках:** Сейчас `Смех.mp3` не воспроизводится при автоматическом отпрыгивании камня от курсора. Требуемое поведение: воспроизводить смех при каждом реально выполненном отскоке сцены 1.
  - **Источник:** «Верни звук Смех после каждого отпрыгивания»
  - **Acceptance hint:** Автоматический отскок увеличивает счётчик запусков смеха ровно на один.

- **Отсутствующий Camen при фейковом клике:** Сейчас фейковый клик запускает смех, но не `Camen.mp3`. Требуемое поведение: фейковый клик запускает оба звука независимо.
  - **Источник:** «При фейковом клике включай звук Camen»
  - **Acceptance hint:** Один принятый фейковый клик даёт по одному запуску каждого файла.
