## Исходный текст

Для Сцены 1 пользователь просит добавить в UI режим выбора изображений из папки `assets/gogh`: независимый случайный выбор, случайный выбор без повторов внутри цикла и постоянный показ одной выбранной картинки. Для режима одной картинки нужен расположенный ниже активный `select`. Из UI Сцены 1 также требуется убрать группу Fold и параметры «Высота страницы», «Изображение камня в fold-зеркале», «Вход в нижнюю и боковые стены», «Размер после запуска физики» и «Конечный размер».

---

## Функциональные требования

- **Выбор режима показа картин:** В UI Сцены 1 должен появиться параметр «Режим выбора картин» с вариантами «Случайная картинка», «Случайно циклично» и «Одна картинка».
  - **Пояснение:** Пользователь должен управлять способом выбора изображения для popup, открываемого фейковым кликом.
  - **Источник:** "Дай возможность на UI выбирать режим какие картинки из gogh вариации".
  - **Acceptance hint:** Открыть настройки Сцены 1 и убедиться, что доступны ровно три указанных режима.

- **Случайная картинка:** При каждом фейковом клике система должна независимо выбирать случайное изображение из `assets/gogh`; одна и та же картинка может выпасть несколько раз подряд.
  - **Пояснение:** Режим использует выбор с возвращением и не ведёт историю цикла.
  - **Источник:** "случайная картинка из папки gogh".
  - **Acceptance hint:** Подменить источник случайности в тесте и проверить независимый выбор, включая последовательный повтор одного изображения.

- **Случайно циклично:** В пределах одного цикла система должна случайно выбирать только изображения, которые ещё не показывались в этом цикле. После показа всех доступных изображений должен начинаться новый случайный цикл.
  - **Пояснение:** Повторы запрещены внутри цикла, но первое изображение нового цикла выбирается заново случайно и может совпасть с последним изображением предыдущего цикла.
  - **Источник:** "случайна циклично (случайная из которые еще не показывались в данном цикле, затем заново из случайная из цикла)".
  - **Acceptance hint:** При количестве фейковых кликов, равном удвоенному числу картин, проверить два полных цикла без повторов внутри каждого цикла.

- **Одна картинка:** В режиме «Одна картинка» каждый фейковый клик должен открывать одно и то же выбранное изображение.
  - **Пояснение:** Выбор сохраняется до изменения пользователем или безопасного fallback при отсутствии файла.
  - **Источник:** "одна картинка (при каждом фейковом клике открывается одна и та же картинка)".
  - **Acceptance hint:** Выбрать конкретный файл и выполнить несколько фейковых кликов — все popup должны показывать его.

- **Выбор конкретного изображения:** Непосредственно под параметром режима должен находиться `select` со всеми доступными изображениями из `assets/gogh`. В режиме «Одна картинка» он активен, в остальных режимах виден, но неактивен.
  - **Пояснение:** Пользователь сохраняет выбранное значение при переходе между режимами, но оно влияет на popup только в режиме одной картинки.
  - **Источник:** "При выборе \"одна картинка\" нужен внизу активный select с выбором конкретного изображения".
  - **Acceptance hint:** Переключать режимы и проверить мгновенное изменение disabled-состояния расположенного ниже `select`.

- **Состав списка изображений:** Варианты выбора и источники случайных режимов должны формироваться из поддерживаемых файлов изображений в `assets/gogh`, а не из жёстко заданного списка `01.png`–`03.png`. В `select` должны отображаться понятные имена файлов в стабильной алфавитной сортировке.
  - **Пояснение:** Новая вариация Gogh должна подключаться добавлением поддерживаемого файла в папку, без ручного изменения runtime-списка.
  - **Источник:** "какие картинки из gogh вариации".
  - **Acceptance hint:** Добавить тестовый файл в набор импортов и проверить его наличие в options и обоих случайных режимах.

- **Жизненный цикл случайного цикла:** Новый цикл режима «Случайно циклично» должен начинаться при выборе этого режима, перезапуске и новой загрузке Сцены 1.
  - **Пояснение:** История использованных картин относится только к текущему запуску Сцены 1 и не сохраняется как настройка.
  - **Источник:** "в данном цикле, затем заново".
  - **Acceptance hint:** Частично использовать цикл, перезапустить сцену и убедиться, что ограничение предыдущего цикла не переносится.

- **Сохранение настройки:** Выбранный режим и конкретное изображение должны сохраняться и восстанавливаться через действующую систему локальных, комнатных и шаблонных настроек Сцены 1.
  - **Пояснение:** Новые контролы должны вести себя так же, как существующие параметры popup.
  - **Источник:** "Дай возможность на UI выбирать режим".
  - **Acceptance hint:** Изменить значения, перезагрузить страницу, экспортировать и импортировать шаблон — значения сохраняются.

- **Удаление группы из UI Сцены 1:** Группа `3D Fold` со всеми вложенными параметрами не должна отображаться в настройках Сцены 1.
  - **Пояснение:** Механика и общая схема данных не удаляются; группа остаётся доступной в других сценах, где используется.
  - **Источник:** "Убери категории и параметры: ... fold".
  - **Acceptance hint:** В Сцене 1 группа отсутствует, в Сценах 2 и 3 сохраняется.

- **Удаление отдельных параметров из UI Сцены 1:** В настройках Сцены 1 не должны отображаться «Высота страницы», «Изображение камня в fold-зеркале», «Вход в нижнюю и боковые стены, %», «Размер после запуска физики, %» и «Конечный размер, %».
  - **Пояснение:** Значения, runtime-механики и доступность этих параметров в других сценах сохраняются.
  - **Источник:** "Убери категории и параметры: \"высота страницы\", ... \"изображение камня в fold-зеркале\", \"вход в нижнюю и боковую стены\", \"размер послде запуска физики\", \"конечный размер\"".
  - **Acceptance hint:** Проверить отсутствие пяти контролов в Сцене 1 и их сохранение в релевантных других сценах.

## Нефункциональные требования

- **Немедленная реакция UI:** Disabled-состояние `select` конкретной картинки должно обновляться сразу при смене режима без перезагрузки страницы.
  - **Пояснение:** Зависимость контролов должна использовать существующий реактивный механизм панели настроек.
  - **Источник:** "При выборе \"одна картинка\" нужен внизу активный select".
  - **Acceptance hint:** Проверить переключение состояния в браузерном smoke-тесте.

- **Совместимость сохранённых данных:** Старые настройки без новых полей должны мигрировать на режим «Случайно циклично» и первый доступный файл по алфавиту без ошибок загрузки.
  - **Пояснение:** Обновление схемы не должно ломать существующие localStorage, room settings и шаблоны.
  - **Источник:** Одобренные значения по умолчанию из согласованного черновика.
  - **Acceptance hint:** Прогнать миграционные тесты на payload предыдущей версии схемы.

- **Устойчивость выбора:** Если ранее выбранный файл больше отсутствует, система должна использовать первый доступный файл и продолжить работу без runtime-ошибки.
  - **Пояснение:** Устаревшая сохранённая настройка не должна блокировать popup.
  - **Источник:** Одобренный fallback из согласованного черновика.
  - **Acceptance hint:** Передать неизвестный ID изображения и проверить нормализацию к первому варианту.

- **Расширяемость каталога:** Добавление поддерживаемого изображения в `assets/gogh` должно включать его в `select` и случайный выбор без ручного расширения runtime-массива.
  - **Пояснение:** Каталог файлов должен быть единым источником списка вариаций Gogh.
  - **Источник:** "картинки из gogh вариации".
  - **Acceptance hint:** Проверить построение каталога через glob/import-механизм сборщика.

## Проблемы и замечания, превращённые в требования

- **Жёстко заданная последовательность:** Сейчас popup циклически показывает только `01.png`–`03.png` в фиксированном порядке. Требуемое поведение: выбирать изображение одним из трёх настраиваемых способов и использовать весь поддерживаемый каталог `assets/gogh`.
  - **Источник:** "Дай возможность на UI выбирать режим какие картинки из gogh вариации".
  - **Acceptance hint:** Убедиться, что runtime больше не содержит ручных импортов только трёх картин и соблюдает выбранный режим.

- **Перегруженный UI Сцены 1:** Сейчас Сцена 1 показывает группу Fold и параметры, не нужные для её настройки. Требуемое поведение: скрыть перечисленные элементы только в панели Сцены 1.
  - **Источник:** "Убери категории и параметры".
  - **Acceptance hint:** Сравнить набор контролов трёх сцен и проверить scene-specific фильтрацию.
