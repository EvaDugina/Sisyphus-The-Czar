## Функциональные требования

- **Все звуки боковой стены доступны:** СЦЕНА 2 должна проигрывать любой выбранный в UI звук касания боковой стены, включая «Симуляцию оргазма».
  - **Пояснение:** Для СЦЕНЫ 2 больше не применяется специальная фильтрация отдельных аудиофайлов бокового столкновения.
  - **Источник:** «Убери блок на звуки в сцене 2».
  - **Acceptance hint:** После выбора каждого доступного файла новое касание боковой стены увеличивает счётчик воспроизведения и фиксирует выбранное имя файла.

- **Управление через UI:** Выбранный в UI звук боковой стены должен применяться и сохраняться в СЦЕНЕ 2 так же, как в других сценах.
  - **Пояснение:** Сцена не должна скрыто заменять выбранный файл значением `none` или другим файлом.
  - **Источник:** Утверждённый пользователем черновик требований.
  - **Acceptance hint:** После выбора звука runtime содержит то же имя файла и воспроизводит его при следующем новом контакте со стеной.

- **Опция «Без звука»:** Значение `none` / «Без звука» должно продолжать отключать звук боковой стены.
  - **Пояснение:** Удаляется только специальный блок по сцене, а явный пользовательский выбор тишины сохраняется.
  - **Источник:** Утверждённый пользователем черновик требований.
  - **Acceptance hint:** При выбранном `none` новый контакт со стеной не увеличивает счётчик воспроизведения.

- **Новое касание:** Звук должен запускаться только при переходе к контакту с боковой стеной после отсутствия контакта или после перехода к другой стене.
  - **Пояснение:** Постоянный контакт не должен циклически перезапускать звук.
  - **Источник:** Утверждённый пользователем черновик требований.
  - **Acceptance hint:** Повторная установка позиции на той же стене без отхода не создаёт дополнительного воспроизведения.
