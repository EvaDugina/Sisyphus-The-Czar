## Исходный текст

Пользователь сообщил: «Кнопка "сохранить" уже должна выполнять функцию "сохранить для комнаты" оставь только кнопку рядом с версией версией. кнопку "сохранить для кумнаты" убери». После формализации пользователь одобрил трактовку: компактная кнопка рядом с названием версии одновременно сохраняет или обновляет именованную версию и применяет текущие настройки к комнате; отдельная полноразмерная кнопка удаляется.

---

## Функциональные требования

- **Единая кнопка сохранения:** В блоке версий должна остаться только компактная кнопка с иконкой сохранения рядом с названием версии.
  - **Пояснение:** Дублирующее полноразмерное действие не должно занимать место и создавать два разных пути сохранения.
  - **Источник:** «оставь только кнопку рядом с версией».
  - **Acceptance hint:** В блоке версий присутствует одна кнопка сохранения; отдельной кнопки «Сохранить для комнаты» нет.

- **Сохранение именованной версии:** Нажатие компактной кнопки должно сохранить новую именованную версию или обновить выбранную версию по существующим правилам.
  - **Пояснение:** Объединение действий не отменяет текущую функцию управления именованными версиями.
  - **Источник:** Утверждённая трактовка: компактная кнопка выполняет оба действия.
  - **Acceptance hint:** Новое название создаёт одну версию; повторное сохранение выбранной версии обновляет её без дубликата.

- **Сохранение для комнаты:** То же нажатие компактной кнопки должно применить текущие настройки к комнате для всех участников.
  - **Пояснение:** Компактная кнопка заменяет отдельное room-save действие.
  - **Источник:** «Кнопка "сохранить" уже должна выполнять функцию "сохранить для комнаты"».
  - **Acceptance hint:** После нажатия другой участник комнаты получает актуальные настройки.

- **Удаление отдельной кнопки:** Полноразмерная кнопка «Сохранить для комнаты» должна быть удалена из интерфейса и клавиатурной навигации.
  - **Пояснение:** После объединения действий отдельный контрол становится дублирующим.
  - **Источник:** «кнопку "сохранить для кумнаты" убери».
  - **Acceptance hint:** В DOM нет отдельного элемента `.settings-room-save`, а компоновка блока версий остаётся целой.

- **Единый статус результата:** После объединённого действия интерфейс должен сообщать об успешном сохранении либо показывать понятную ошибку, если одно из действий не выполнено.
  - **Пояснение:** Пользователь не должен получать сообщение о полном успехе при частично неуспешной операции.
  - **Источник:** Утверждённый черновик требований.
  - **Acceptance hint:** Успех отображается только после завершения сохранения версии и комнаты; ошибка room-save не маскируется успехом version-save.

## Нефункциональные требования

- **Доступность:** Компактная кнопка должна оставаться доступной мышью и клавиатурой и иметь понятное accessible name.
  - **Пояснение:** Удаление второго контрола не должно ухудшать доступность единственного пути сохранения.
  - **Источник:** Утверждённый черновик требований.
  - **Acceptance hint:** Кнопка получает фокус по Tab и активируется Enter/Space.

- **Отсутствие дубликатов:** Повторное сохранение выбранной версии не должно создавать дубликат записи.
  - **Пояснение:** Объединённое действие сохраняет существующую семантику версии.
  - **Источник:** Утверждённый черновик требований.
  - **Acceptance hint:** После двух сохранений выбранной версии в списке остаётся одна запись с обновлённым содержимым.

## Проблемы и замечания, превращённые в требования

- **Дублирующие действия сохранения:** Сейчас компактная кнопка сохраняет именованную версию, а отдельная полноразмерная кнопка сохраняет настройки комнаты. Требуемое поведение: единая компактная кнопка выполняет обе операции, отдельная кнопка удалена.
  - **Источник:** «Кнопка "сохранить" уже должна выполнять функцию "сохранить для комнаты" ... кнопку "сохранить для кумнаты" убери».
  - **Acceptance hint:** Один пользовательский action обновляет версию и room settings, после чего отображается единый результат.
