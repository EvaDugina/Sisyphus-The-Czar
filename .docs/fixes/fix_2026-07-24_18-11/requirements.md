## Исходный текст

Пользователь попросил сделать плавнее автоматический скролл страницы до верха при касании камнем своего полупрозрачного следа, после которого наступает тёмная тема. Нужно добавить на UI параметры плавности скролла: время и cubic-bezier. Время автоскролла должно задаваться в секундах от 0 до 10, дефолт 4 секунды. Новые параметры должны вести себя как остальные UI-параметры. Также нужно добавить ползунки времени затухания дождя и времени появления дождя от 0 до 20 секунд с шагом 0.1 секунды.

---

## Функциональные требования

- **Плавный автоскролл страницы наверх:** При касании камнем собственного полупрозрачного следа система должна автоматически скроллить страницу до верха.
  - **Пояснение:** Это скорость автоматического скролла страницы, а не камера, игровое поле или отдельная анимация темы.
  - **Источник:** "Скорость автоматического скролла страницы до верха при касании камнем своего полупрозрачного следа."
  - **Acceptance hint:** При срабатывании события страница плавно прокручивается к верхней позиции.

- **Настройка времени автоскролла:** В UI должен быть параметр времени автоскролла страницы до верха в секундах.
  - **Пояснение:** Диапазон от `0` до `10` секунд, значение по умолчанию `4` секунды.
  - **Источник:** "По секундам от 0 до 10. Дефолт 4."
  - **Acceptance hint:** Изменение значения в UI меняет длительность автоскролла.

- **Настройка easing через cubic-bezier:** В UI должен быть параметр `cubic-bezier` для автоскролла страницы до верха.
  - **Пояснение:** Параметр управляет кривой плавности автоскролла.
  - **Источник:** "дай параметр плавности скролла (время и cubic bezier) на UI"
  - **Acceptance hint:** Изменение `cubic-bezier` меняет характер ускорения и замедления автоскролла.

- **Поведение параметров как у остальных UI-настроек:** Новые параметры скролла должны быть добавлены в UI и обрабатываться так же, как остальные параметры на UI.
  - **Пояснение:** Если существующие параметры сохраняются или применяются в общем механизме настроек, новые параметры должны следовать тому же паттерну.
  - **Источник:** "Добавь их на UI и там как с остальными параметрами на UI."
  - **Acceptance hint:** Новые настройки видны и ведут себя консистентно с существующими настройками.

- **Ползунок времени затухания дождя:** В UI должен быть ползунок времени затухания дождя.
  - **Пояснение:** Диапазон от `0` до `20` секунд, шаг `0.1` секунды.
  - **Источник:** "Дай для времени затухания ... дождя ползунки от 0 до 20 секунд. Деление делай 0.1 секунда."
  - **Acceptance hint:** Пользователь может выставить время затухания дождя с точностью до `0.1` секунды.

- **Ползунок времени появления дождя:** В UI должен быть ползунок времени появления дождя.
  - **Пояснение:** Диапазон от `0` до `20` секунд, шаг `0.1` секунды.
  - **Источник:** "Дай для времени ... появления дождя ползунки от 0 до 20 секунд. Деление делай 0.1 секунда."
  - **Acceptance hint:** Пользователь может выставить время появления дождя с точностью до `0.1` секунды.

## Нефункциональные требования

- **Визуальная плавность автоскролла:** Автоскролл страницы до верха должен восприниматься более плавным и менее резким.
  - **Пояснение:** При дефолтной длительности `4` секунды переход наверх не должен выглядеть рывком.
  - **Источник:** "делай скролл плавнее"
  - **Acceptance hint:** При дефолтной длительности `4` секунды переход наверх визуально мягче текущего поведения.

  - **Источник:** "При попаданиии камня в свой полупрозрачный след после которого наступает темная тема - делай скролл плавнее..."
  - **Acceptance hint:** После касания следа страница скроллится наверх с длительностью и кривой, заданными в UI.
