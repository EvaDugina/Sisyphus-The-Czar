## Исходный текст

После первого нажатия на камень непрерывно воспроизводить загруженный
`Капель.mp3`. Громкость должна плавно зависеть от физической высоты камня:
начальная громкость по умолчанию `0.1`, конечная — `1`, зависимость настраивается
визуальным cubic-bezier-редактором в отдельном разделе UI. Добавить выключенное
по умолчанию правило непрерывного финального падения с вершины и отдельный таймер
его активации от 0 до 10 секунд, по умолчанию 2 секунды. Таймер только разрешает
правило для последующего отпускания и сбрасывается, если камень покинул вершину
до истечения времени. После каждого нового касания нижней земли проигрывать
случайный звук из `assets/audio/gachi/`. Удалить надпись
`СМЕРТИЮ СМЕРТЬ ПОПРАВ`. Приложение используется только в одиночных сессиях.

## Функциональные требования

- **Запуск «Капели»:** После первого нажатия на камень система должна запустить
  непрерывное циклическое воспроизведение `Капель.mp3` до закрытия или
  перезагрузки страницы.
  - **Пояснение:** Повторные нажатия не должны создавать дополнительные
    одновременно играющие экземпляры звука.
  - **Источник:** "После первого клика включай звук «Капель.mp3»"
  - **Acceptance hint:** До нажатия на камень звук не играет; после первого
    нажатия играет один циклический экземпляр; повторные нажатия не дублируют его.

- **Громкость по физической высоте:** Система должна вычислять громкость
  «Капели» по физическому положению камня между нижней землёй и вершиной.
  - **Пояснение:** На земле применяется начальная громкость, на вершине —
    конечная, а промежуточные значения интерполируются одной cubic-bezier-кривой
    в обоих направлениях движения.
  - **Источник:** "Чем выше камень — тем громче, чем ниже, тем тише"
  - **Acceptance hint:** Внизу громкость равна начальному значению, наверху —
    конечному, при подъёме и спуске она следует выбранной кривой.

- **Раздел UI «Капель»:** Система должна предоставить отдельный раздел
  настроек «Капель» с начальной громкостью `0–1` (по умолчанию `0.1`), конечной
  громкостью `0–1` (по умолчанию `1`) и визуальным редактором cubic-bezier.
  - **Пояснение:** Редактор должен использовать существующий формат с графиком,
    управляющими точками, координатами, строковым значением и preview.
  - **Источник:** "Для капель создай отдельный раздел на ui параметрах"
  - **Acceptance hint:** Все три контрола видны в отдельной секции, применяются
    без reload и восстанавливаются существующим механизмом настроек.

- **Переключатель финального падения:** Система должна предоставить
  выключенный по умолчанию переключатель правила, по которому отпущенный на
  вершине камень переходит в непрерывное падение и не останавливается повторно
  на верхнем отпечатке.
  - **Пояснение:** При выключенном правиле отпускание на вершине использует
    обычное поведение без принудительного финального падения.
  - **Источник:** "Дай возможность на UI отключить это правило"
  - **Acceptance hint:** Значение по умолчанию — `false`; переключатель
    однозначно меняет поведение последующего отпускания на вершине.

- **Таймер активации финального падения:** Система должна предоставить таймер
  от 0 до 10 секунд с шагом 0.1 секунды и значением по умолчанию 2 секунды.
  - **Пояснение:** Это отдельный служебный таймер, не связанный с отображаемым
    секундомером вершины. Он запускается при попадании камня на вершину, не
    отпускает камень автоматически и только разрешает непрерывное падение при
    последующем отпускании.
  - **Источник:** "Дай на UI параметр таймера до включения этого правила после
    нахождения камня на верхушке. От 0 до 10 секунд. По умолчанию 2"
  - **Acceptance hint:** До истечения задержки отпускание не активирует правило;
    после истечения — активирует; автоматического отпускания нет.

- **Сброс таймера вершины:** Система должна сбрасывать служебный таймер, если
  камень покинул вершину до истечения установленной задержки.
  - **Пояснение:** При новом попадании на вершину начинается новый отсчёт.
  - **Источник:** "Таймер должен сбрасываться, если камень покинул вершину до
    истечения времени"
  - **Acceptance hint:** Повторный вход после преждевременного выхода не
    наследует накопленное время.

- **Gachi-звук при касании земли:** При каждом новом переходе камня из воздуха
  в соприкосновение с нижней землёй система должна локально воспроизводить
  случайный файл из `assets/audio/gachi/`.
  - **Пояснение:** Один непрерывный контакт считается одним касанием; после
    отрыва и следующего контакта создаётся новое событие. Последовательный
    случайный выбор может повторить предыдущий файл.
  - **Источник:** "После каждого касания камнем земли включай произвольный звук
    из папки gachi"
  - **Acceptance hint:** Одно падение даёт один звук, неподвижный контакт не
    повторяет звук на каждом кадре, новый контакт снова воспроизводит звук.

- **Удаление надписи:** Система не должна отображать элемент с текстом
  `СМЕРТИЮ СМЕРТЬ ПОПРАВ` и не должна оставлять под него пустое место.
  - **Пояснение:** Удаляется сам элемент вершины, а не только видимый текст.
  - **Источник:** "Убери надпись смертию смерть поправ"
  - **Acceptance hint:** Текст и соответствующий элемент отсутствуют в DOM.

## Нефункциональные требования

- **Безопасная громкость:** Система должна ограничивать итоговую громкость
  «Капели» диапазоном `0–1`.
  - **Пояснение:** Невалидные настройки не должны передаваться в Audio API.
  - **Источник:** "Диапазон UI — 0–1. Да"
  - **Acceptance hint:** Для любых сохранённых значений `audio.volume` остаётся
    в диапазоне `0–1`.

- **Плавное аудио:** Система должна обновлять громкость «Капели» непрерывно, без
  слышимых скачков при движении камня.
  - **Пояснение:** Громкость вычисляется из текущей физической высоты в рабочем
    цикле приложения.
  - **Источник:** "График cubic bezier изменения громкости"
  - **Acceptance hint:** При последовательном подъёме значения громкости
    изменяются согласно кривой без дискретных переключений.

- **Устойчивость аудио:** Запрет autoplay, ошибка загрузки или ошибка
  воспроизведения не должны останавливать приложение.
  - **Пояснение:** Ошибки Audio API обрабатываются локально.
  - **Источник:** Выведено из требования запускать звук после пользовательского
    взаимодействия.
  - **Acceptance hint:** Отклонённый `play()` не вызывает необработанного
    исключения и не ломает физический цикл.

- **Сохранение настроек:** Новые UI-настройки должны сохраняться после
  перезагрузки и входить в существующие шаблоны настроек.
  - **Пояснение:** Используется общий механизм настроек приложения.
  - **Источник:** Согласованное поведение текущих UI-настроек.
  - **Acceptance hint:** Изменённые значения восстанавливаются после reload и
    при выборе сохранённого шаблона.

- **Отсутствие дублей:** Система не должна повторно проигрывать gachi-звук на
  каждом кадре непрерывного контакта с землёй.
  - **Пояснение:** Триггером является граница перехода из воздуха на землю.
  - **Источник:** "После каждого касания"
  - **Acceptance hint:** Счётчик воспроизведений увеличивается один раз на
    контакт.

- **Production-совместимость:** Production-сборка без отладочной панели должна
  продолжать собираться и работать.
  - **Пояснение:** Настройки доступны runtime и при скрытом UI.
  - **Источник:** Архитектурное ограничение текущего приложения.
  - **Acceptance hint:** `npm run build` завершается успешно.

## Проблемы и замечания, превращённые в требования

- **Отсутствует звуковой слой «Капель»:** Сейчас `Капель.mp3` не
  воспроизводится. Требуемое поведение: один постоянный циклический звуковой
  слой после первого нажатия на камень с громкостью по высоте.
  - **Источник:** "После первого клика включай звук «Капель.mp3»"
  - **Acceptance hint:** Проверяется первый запуск, отсутствие дублей и изменение
    громкости.

- **Финальное падение не настраивается:** Сейчас правило нельзя отключить или
  отложить. Требуемое поведение: выключенный по умолчанию переключатель и
  отдельный таймер активации.
  - **Источник:** "Дай возможность на UI отключить это правило"
  - **Acceptance hint:** Оба состояния переключателя и границы таймера покрыты
    тестами.

- **Касание земли не озвучено:** Сейчас новое соприкосновение с землёй не
  воспроизводит случайный gachi-звук. Требуемое поведение: один случайный звук
  на новый контакт.
  - **Источник:** "После каждого касания камнем земли включай произвольный звук"
  - **Acceptance hint:** Два раздельных контакта дают два воспроизведения.

- **Лишняя надпись на вершине:** Сейчас отображается
  `СМЕРТИЮ СМЕРТЬ ПОПРАВ`. Требуемое поведение: надпись и её элемент отсутствуют.
  - **Источник:** "Убери надпись смертию смерть поправ"
  - **Acceptance hint:** Элемент отсутствует в DOM и не резервирует место.
