## Исходный текст

Пользователь сообщил, что камера не следует за поднимающимся камнем, и потребовал двунаправленное слежение при подъёме и падении. Также необходимо заменить «Путь царей» на `The Path of Tzarey`, «миниатюра» на `miniature` и использовать для этих двух текстов локальный шрифт из `assets/fonts`.

## Функциональные требования

- **Двунаправленное слежение камеры:** В Сцене 2 камера должна с lerp следовать за камнем как при его подъёме, так и при падении.
  - **Пояснение:** `cameraFollowDownEnabled` остаётся включённым по умолчанию, а `upperZoneAutoScrollEnabled` меняет default с `false` на `true`. При миграции настроек без этого параметра применяется `true`. Существующие UI-переключатели направлений сохраняются и позволяют явно отключить отдельное направление. Скрытый `overflow-y` не препятствует программному слежению.
  - **Источник:** "Камера должна следовать за камнем и когда он поднимается и когда он падает!"
  - **Acceptance hint:** При настройках по умолчанию камера плавно движется за камнем вверх и вниз; отключение соответствующего переключателя запрещает только выбранное направление.

- **Переименование заголовка:** Все пользовательские отображения текста «Путь царей» должны быть заменены точной строкой `The Path of Tzarey`.
  - **Пояснение:** Изменяется пользовательский текст, но не технические имена проекта, package или Docker-сервисов.
  - **Источник:** "Измени название с \"Путь царей\" на \"The Path of Tzarey\""
  - **Acceptance hint:** В пользовательском интерфейсе отсутствует старый текст и отображается новый без изменения регистра.

- **Переименование подписи:** Все пользовательские отображения текста «миниатюра» должны быть заменены точной строкой `miniature`.
  - **Пояснение:** Изменяется соответствующая пользовательская подпись.
  - **Источник:** "замени \"миниатюра\" на \"miniature\""
  - **Acceptance hint:** Подпись отображается как `miniature`; старое русское написание отсутствует.

- **Локальный шрифт для переименованных текстов:** `The Path of Tzarey` и `miniature` должны использовать локальный шрифт Comico Regular из `assets/fonts/Comico_Complete/Fonts/WEB/fonts/`.
  - **Пояснение:** Основным источником используется `Comico-Regular.woff2`, допустим локальный `woff` fallback. Остальной интерфейс не переводится на этот шрифт.
  - **Источник:** "используй для них шрифт из папки assets/fonts"
  - **Acceptance hint:** Computed `font-family` обоих элементов указывает на локальный Comico, внешние font-CDN не запрашиваются.

## Нефункциональные требования

- **Плавность камеры:** Двунаправленное движение должно использовать существующий параметр `cameraFollowLerp` без мгновенных скачков при обычных значениях lerp.
  - **Пояснение:** Исправление направления не заменяет lerp прямым scroll-jump.
  - **Источник:** Требование следовать за камнем вверх и вниз.
  - **Acceptance hint:** Промежуточная позиция камеры находится между текущей и целевой при `cameraFollowLerp < 1`.

- **Совместимость overflow:** Программный camera-follow должен работать при `overflow-y: hidden` и `overflow-y: auto`.
  - **Пояснение:** Визуальное скрытие вертикального overflow не блокирует программный scroll.
  - **Источник:** Требование двунаправленного camera-follow с существующим параметром overflow.
  - **Acceptance hint:** При hidden камера меняет `scrollY` вслед за движущимся вверх или вниз камнем.

- **Стабильность оформления:** Новый шрифт не должен обрезать тексты, ломать их позиционирование или выводить их за доступную область viewport.
  - **Пояснение:** Смена метрик шрифта должна сохранять читаемость текущей композиции.
  - **Источник:** Требование использовать локальный шрифт для двух текстов.
  - **Acceptance hint:** Оба текста видимы целиком на поддерживаемых viewport smoke-проверки.

- **Локальная загрузка:** Шрифтовые файлы должны обслуживаться самим приложением без внешнего CDN.
  - **Пояснение:** Используются предоставленные файлы `assets/fonts`.
  - **Источник:** "используй для них шрифт из папки assets/fonts"
  - **Acceptance hint:** Production build включает локальный font asset.

## Проблемы и замечания, превращённые в требования

- **Камера не следует вверх:** Сейчас default-настройка запрещает движение камеры вверх. Требуемое поведение: по умолчанию оба направления слежения включены.
  - **Источник:** "Сейчас камера не следует за камнем когда он поднимается, а должна"
  - **Acceptance hint:** Default и миграция дают `cameraFollowDownEnabled=true` и `upperZoneAutoScrollEnabled=true`.

- **Устаревшие тексты и шрифт:** Сейчас интерфейс содержит «Путь царей» и «миниатюра» без требуемого локального шрифта. Требуемое поведение: строки заменены на `The Path of Tzarey` и `miniature`, оба элемента используют Comico Regular.
  - **Источник:** "Измени название ... замени ... используй для них шрифт"
  - **Acceptance hint:** Старые строки отсутствуют в UI, новые строки отображаются локальным Comico.
