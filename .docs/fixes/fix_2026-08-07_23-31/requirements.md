## Исходный текст

- По любому клику на камне включать любой звук из папки `gachi`; при падении прекращать воспроизведение всех звуков `gachi`.
- При ударе падающего камня о землю включать звук «Симмуляция Оргазма» — именно контакт с землёй, а не начало падения, должен вызывать этот звук.
- Исправить чёрный экран после перезагрузки страницы: приложение должно восстановить прежнее состояние игры без нажатия «Начать сначала».
- При быстрых повторных кликах звуки `gachi` должны накладываться друг на друга.

## Функциональные требования

- **Звук при клике по камню:** Каждый клик или тап непосредственно по камню должен запускать один произвольно выбранный аудиофайл из папки `gachi`.
  - **Пояснение:** Звук должен быть реакцией только на взаимодействие с камнем.
  - **Источник:** "По любому клику на камне включай любой звук из папки gachi"
  - **Acceptance hint:** Каждый отдельный клик по камню запускает звук из `gachi`; клики вне камня звук не вызывают.

- **Параллельное воспроизведение `gachi`:** Быстрые повторные клики должны создавать независимые экземпляры воспроизведения; уже запущенный звук не должен прерываться новым кликом.
  - **Пояснение:** Несколько звуков могут звучать одновременно.
  - **Источник:** "Да, накладываться"
  - **Acceptance hint:** Несколько быстрых кликов приводят к одновременному воспроизведению нескольких записей.

- **Остановка `gachi` при падении:** При переходе камня в состояние падения система должна остановить все активные экземпляры звуков из папки `gachi`.
  - **Пояснение:** Звуки кликов не должны продолжаться во время падения.
  - **Источник:** "при падении выключи воспроизведение звуков gachi"
  - **Acceptance hint:** При начале падения одновременно прекращаются все наложенные звуки `gachi`.

- **Звук удара о землю:** Подтверждённое столкновение падающего камня с землёй должно однократно запускать звук «Симмуляция Оргазма».
  - **Пояснение:** Начало падения и удар о землю являются разными событиями; звук относится только ко второму.
  - **Источник:** "При падении камня включай звук Симмуляция Оргазма"; "Именно удар о землю должен вызывать звук Симмуляции оргазма"
  - **Acceptance hint:** Звук не запускается в начале падения и воспроизводится один раз при фактическом контакте с землёй.

- **Восстановление после перезагрузки:** После перезагрузки страницы приложение должно восстановить прежнее состояние игровой сессии и отобразить корректно инициализированную сцену.
  - **Пояснение:** Пользователь должен продолжить прежнюю сессию без ручного сброса.
  - **Источник:** "Когда перезагружаю страницу черный экран, спасает только нажатие на «начать сначала»"; "Восстановить прежнее состояние"
  - **Acceptance hint:** Состояние игры до и после обновления страницы совпадает; чёрный экран не появляется и нажатие «Начать сначала» не требуется.

## Нефункциональные требования

- **Точная привязка аудио к событиям:** Система должна запускать и останавливать звуки синхронно с соответствующими событиями камня.
  - **Пояснение:** Начало падения останавливает `gachi`, а подтверждённый удар запускает отдельный звук.
  - **Источник:** "Именно удар о землю должен вызывать звук Симмуляции оргазма"
  - **Acceptance hint:** При одном падении наблюдается правильная последовательность без преждевременного запуска звука удара.

- **Защита от повторного срабатывания:** В рамках одного падения звук удара должен запускаться не более одного раза.
  - **Пояснение:** Повторные физические контакты после приземления не должны дублировать эффект одного падения.
  - **Источник:** "Именно удар о землю должен вызывать звук Симмуляции оргазма"
  - **Acceptance hint:** Одно падение приводит ровно к одному запуску звука удара.

- **Надёжность восстановления:** Сохранённое состояние должно корректно загружаться без ручного сброса игры и без зависания на чёрном экране.
  - **Пояснение:** Перезагрузка страницы является поддерживаемым сценарием продолжения игры.
  - **Источник:** "Когда перезагружаю страницу черный экран"
  - **Acceptance hint:** Повторная загрузка с сохранённым состоянием стабильно отображает игровую сцену.

## Проблемы и замечания, превращённые в требования

- **Чёрный экран после перезагрузки:** Сейчас после перезагрузки может отображаться чёрный экран. Требуемое поведение: сцена восстанавливается из сохранённого состояния и становится доступна без дополнительных действий пользователя.
  - **Источник:** "Когда перезагружаю страницу черный экран, спасает только нажатие на «начать сначала»"
  - **Acceptance hint:** Обновление страницы во время существующей сессии восстанавливает сцену и состояние игры.

- **Неверный момент звука падения:** Звук может быть ошибочно привязан к общему событию падения. Требуемое поведение: «Симмуляция Оргазма» запускается исключительно при ударе камня о землю.
  - **Источник:** "Именно удар о землю должен вызывать звук Симмуляции оргазма"
  - **Acceptance hint:** Начало падения не запускает звук; контакт с землёй запускает его однократно.
