## Approved-карточка

<!-- Этот раздел после аппрува не переписывать. -->

- **Гипотеза:** если заменить непрерывный preclick-parallax на дискретные отскоки от руки, камень будет восприниматься как ускакивающий объект: каждый вход курсора в радиус переместит его от руки, быстрый вход даст более дальний прыжок, а новая позиция сохранится.
- **Аудитория / окружение:** пользователь с мышью до первого захвата камня на `/` и `/drafts/`.
- **Пользовательский процесс:** приближение руки → пересечение радиуса → отскок → новое положение становится исходным для следующего отскока.
- **Затрагиваемый модуль:** локальный preclick runtime и аудио.
- **Предполагаемые области кода:** `src/runtime/createSisyphusRuntime.js`, `src/lib/preclickParallax.mjs`, `tests/smoke/preclick-rock-guidance.spec.js`.
- **Acceptance examples:** flag off полностью сохраняет текущий parallax и возврат; flag on вызывает один прыжок при новом входе в радиус; направление — от курсора; после выхода камень не возвращается; следующий прыжок начинается от предыдущей посадки; быстрый вход даёт большую дистанцию, чем медленный; каждый отскок запускает один звук «Смех»; первый успешный захват завершает preclick-режим как раньше.
- **Метрика / evidence:** Playwright фиксирует стартовую и конечную позиции, сравнивает дистанции и направление, отсутствие возврата, число запусков аудио и поведение flag off. Fixtures используют одинаковые viewport, радиус, старт и траекторию; меняется только скорость движения.
- **Запрещено менять:** серверную физику, восстановление сессии, gachi-звуки, звук удара о землю, room-settings schema.
- **Blast radius:** только preclick-режим мыши при включённом flag.
- **Отключение / rollback:** удалить локальный flag `EXPERIMENT_PRECLICK_ROCK_HOP`; точный файловый rollback выполняется через guard.
- **Предположения:** в проекте нет реализации зайца, поэтому используется существующая кривая `cubic-bezier(0.22, 1, 0.36, 1)` и длительность `400 ms`; скорость `0–2000 px/s` отображается в `0.35–1.25` радиуса с ограничением посадки viewport; после первого захвата поведение не меняется; аудиофайл «Смех» отсутствует и должен быть предоставлен отдельно.
