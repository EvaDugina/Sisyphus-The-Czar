# Inter timer subset

`Inter-Timer-700.woff2` is a Google Fonts text subset of Inter 700 normal.
It contains only `U+0030–U+003A` (digits `0–9` and colon) for the summit
stopwatch.

- Source: https://fonts.google.com/specimen/Inter
- Upstream: https://github.com/rsms/inter
