# 3D Fold draft

Локальная копия основной сцены с экспериментальными перспективными зонами автоматического скролла.

Панель `3D Fold` управляет углом и размером верхней линзы, включает или выключает плавное смешивание и позволяет редактировать его cubic-bezier графиком. Исходная область имеет высоту двух линз: одна часть находится над viewport, вторая — непосредственно под верхней границей экрана.

```bash
npm run dev
```

Открыть `http://127.0.0.1:8080/drafts/`. Страница доступна только через Vite dev server и не входит в production-сборку.
